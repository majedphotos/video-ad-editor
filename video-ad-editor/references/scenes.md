## البنية جاهزة — لا تلمسها

`compose.html` فيه كل شي أساسي:
- الفيديو بالأوضاع، بانتقال ناعم.
- الكابشن، وتظليل الكلمة المنطوقة.
- ورا الراس، البي-رول، المشاهد المولّدة، الملصقات.
- شريط التقدّم، كرت النهاية، واشتقاق الألوان.

**افتراضياً ما يرسم أي مشهد مخصص:** الفيديو ملء الشاشة + كابشن + كرت النهاية.

## شلون تكتب مشهدك

مشاهدك بآخر `compose.html`، بسكربت ثاني تحت سكربت المحرّك:

```html
<script>
SCENES=[{s:0,e:4.1,m:R_FULL},{s:4.1,e:9.8,m:R_DOWN,gb:480},{s:9.8,e:99,m:R_FULL}];
function listPanel(t){
  if(t<4.1||t>9.8) return;
  panelIn(t,4.1,9.8,()=>{ /* رسم بإحداثيات 130..950 × 278..458 */ });
}
SCENE_LIST.push(['listPanel',listPanel]);   // بدون التسجيل ما ينرسم
</script>
```

- `SCENES` تقدر تكتبها بـ`studio.json` بدال الكود.
- كل مشهد ياخذ `t` ويلتصق بتوقيت الكلمة من `caps.json` — لا بتوقيت تقريبي.
  - `wordsOf(i)` = كلمات الجملة رقم i (العدّ من صفر).
- مشهد يشتغل على صورة الفيديو نفسها (مثل القليتش) ينرسم بطبقة الفيديو:
  `SCENE_LIST.push(['myFx',myFx,'video'])`
- من الاستوديو: `studio.json` ← `"sceneFx":["listPanel"]` يسجّل بالاسم.
- مشهد يطيح ينطبع بالطرفية `[compose] ⚠️ مشهد متخطّى` — صلّحه، لا تتجاهله.
- أمثلة للقراءة: `scripts/compose.EXAMPLES.js` (راسه يشرح شلون تحمّله).

### حزمة الموشن — بكل فيديو فيه أرقام أو شرح

`scripts/motion-kit.js` فيها:

## الفكرة — استعارة بصرية، مو زينة

اعصف 3-4 أفكار لكل جملة. الفكرة **تمثّل اللي يقوله**:

| يقول | المشهد |
|---|---|
| يعدّد أشياء | بطاقات تدخل وحدة مع كل كلمة، ثم تنقلب بعلامة صح |
| رقم أو سعر | عدّاد يلف وينزل على الرقم بضربة |
| «انكسر» أو «خطأ» | قليتش يزحزح شرائح الصورة + شقوق |
| مشكلة ثم إصلاح | الكرت يسوَدّ بتحذير ← شريط تقدّم + قائمة تتعلّم بصح |
| «ملف واحد» | كرت ملف، وبطاقات تطير وتندمج فيه |
| دعوة للتعليق | مربع تعليق، والكلمة تنكتب كلمة كلمة |

الجدول أمثلة، مو قالب. **اخترع جديد كل مرة.**

## تفاصيل التخطيط

- `R_DOWN` **كرت مرن:** يصغر حسب أسفل الرسم (`gb`) وعدد أسطر الكابشن.
  فالرسم والكابشن ما يتزاحمان. اللوحات داخل `panelIn()` تتكبّر 1.2 وحدها.
- «ملء الشاشة» يُعرف بالمساحة (`isFull()`) — مو بالزوايا.
- `{s,e,m,nocap:true}` = مشهد بلا كابشن (لما اللوحة فيها النص نفسه).
- شبكة خفيفة بالخلفية كل 60px. توقفها بـ`theme.json` ← `grid:false`.

### اختيار الوضع — قرارك من معنى الكلام

أمر المستخدم (28 سبتمبر): «ما تلتزم بقاعدة… تدرس السكربت وتقرر كرت صغير، اختفي، أو نص في نص».

اقرأ السكربت كامل، ولكل جملة اسأل: **الوجه أهم ولا الرسمة؟**
- انفعال، سؤال، وعد ← الوجه يكبر.
- أرقام وشرح ← الرسمة تاخذ المساحة (`R_LOWER` أو `R_OFF`).
- تعليق على رسمة ← `R_DOWN`.

نصايح مو قيود: الهوك غالباً أقوى بالوجه، والتنويع بين الأوضاع يشد.
الثابت بس: الكابشن ما ينكتب على الوجه، والمنطقة الآمنة.

## البي-رول (اختياري)

فيديو ثانٍ من الشركة؟
1. استخرج المفيد فريمات: `<work>/broll/<اسم>_%04d.jpg`
2. عرّف مداه بـ`BR_NEED`.
3. اعرضه بـ`brCard()` مع `R_LOWER`.
4. `BRCROP` يقصّ الترجمة المحروقة.

3-4 لقطات بالفيديو تكفي.
`R_LOWER` يدخل حزام انستقرام عن قصد — مسموح لأن المغطّى صورة، مو نص.
