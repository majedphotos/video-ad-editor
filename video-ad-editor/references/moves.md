# بنك الحركات — كل فيديو له لوحة حركات، وأنت تختار بوعي

بنك حركات مرقّم يكبر مع الوقت (`motion/moves/catalog.json` — 108 حركات: 100 من 17 أكتوبر + 101 «قائمة تنكشف» بـ6.5 + 102 «تفكيك الطبقات» + 103 «تحوّل النقاط» + 104 «تيار الخطوط» + 105 «قطرات تندمج» + 106 «مكعبات تنبني» + 107 «صوتك يرسم» + 108 «حروف ترسم الصورة»). كل حركة: دالة جاهزة بـ`motion/moves.js` + معاينة 4 ث + مصدرها.
**قرار المستخدم (13 أكتوبر):** «ابيك تكون غني بالحركات… وتكون واعي». هو ما يختار حركة حركة. أنت تختار لكل فيديو.

## 1) لوحة الفيديو (إلزامي قبل أول مشهد)

```bash
python3 scripts/35_moves.py plan --title "<عنوان الفيديو>" --family auto --cues number,cta
```
يطلع **لوحة** الفيديو:
- **العائلة** (`family`): لون الحركة للفيديو كله. `calm` هادي · `punch` طاقة · `onetake` كاميرا مستمرة بلا قص · `editorial` تحريري/شرح.
  `auto` = اللي ما انستخدمت من زمان. اختر بنفسك لو الفيديو واضح: نصيحة هادية = `calm`، هوك وأرقام = `punch`، فكرة وحدة تتطور = `onetake`، شرح وخطوات = `editorial`.
- **3 أساسيات** (`core`): حركة كلمات + انتقال + كاميرا أو كرت. **الفيديو كله يدور حولها**، مثل الونشوت: نفس اللغة البصرية من أوله لآخره.
- **لهجات** (`accents`، أكثر شي 2): حركة خاصة للحظة خاصة بس. `--cues` = اللحظات اللي بالسكربت:
  `number` رقم قوي · `list` نقاط · `price`/`cta` سعر أو طلب · `contrast` مقارنة · `emphasis` كلمة مفتاح · `reveal` كشف · `tech` تقنية · `hit` ضربة.
- **قواعد** (`rules`): تمشي على التوقيت دايماً (مثلاً J-cut).
- **ستايل** (`style`): شكل الفيديو كله — سطح وملمس وخط وكروت (17 ستايل، أو دمج `a+b`). التفاصيل والكود: `references/styles.md`. و`moments` = ستايل لحظة (VHS/بروتالي) للهوك أو الطلب بس.
- ينحفظ بسجل `moves-history.json`، فالأساسيات تتغير من فيديو لفيديو. قل للمستخدم بسطر: «لوحة هالفيديو: طاقة — طلعة متتابعة + سحبة + إشعارات».

## 2) الإيقاع داخل الفيديو

1. **كل 2–4 ث يصير شي** (حسب `pace` بالبروفايل). مو كل جملة لازم حركة: الجمل العادية تمشي على الكابشن بس.
2. **حركة الكلمات الأساسية** على الجمل المهمة. **الانتقال الأساسي** عند تغيّر المشهد أو الفكرة بس. **الكاميرا الأساسية** مرة وحدة بالمشهد أكثر شي.
3. **اللهجة** بلحظتها بس (الرقم، السعر، الضربة)، ولا تتكرر.
4. ⛔ لا نفس الحركة مرتين ورا بعض. ولا تجيب حركة من برّا اللوحة إلا لو الجملة ما يخدمها شي من اللوحة، وقلها بسطر.
5. **الحركة من معنى الجملة**: اللوحة تحدد اللغة، والجملة تحدد وين ومتى. مثلاً «من 0 لـ1000» = العدّاد، مو أي حركة. **والبنك ما يحدّك:** أقوى لحظات صاحب البلقن كانت اختراع من الجملة — «نسخ» ← 3 نسخ منه، «أفكار موجودة أصلاً» ← جدار بطاقات ورا ظهره. لو الجملة تستاهل شي مو بالبنك، اخترعه.
6. `off` بالبروفايل (لو منع شي من المعرض) ممنوع نهائياً. `on` يقدّمها بالاختيار. والاثنين اختياريين: الافتراضي إنه ما يختار.

## 3) الاستخدام بالكود

**بمحرّك الموشن** (`motion/` — فيلم الموشن، الونشوت، أي مشهد ينرسم بـ`render.js`): نادِ الدالة مباشرة.
```js
draw(t, lt, ctx) {
  const { X, P, FX } = ctx;
  X.fillStyle = P.bg; X.fillRect(0, 0, ctx.W, ctx.H);
  FX.riseUp(ctx, t, { text: 'الفكرة أهم من الأداة', s: ctx.wordTime('l2', 0).s, accent: [1] });    // 3 طلعة متتابعة
  FX.whip(ctx, t, { s: 4.2, A: Y => drawIntro(Y), B: Y => drawStats(Y) });                         // 11 سحبة
  const tau = FX.ramp(t, { hit: ctx.wordTime('l3', 2).s });                                          // 20 تبطيء الضربة: استخدم tau مكان t
}
```
- الألوان من `ctx.P` (ثيم المستخدم) تلقائياً. لا تمرر ألوان ثابتة.
- `o.s` لازم يكون توقيت كلمة حقيقية (`ctx.wordTime`). `FX.caption` ياخذ `line: 'l2'` ويتزامن مع الصوت كلمة كلمة.
- الانتقالات (`crossZoom softWipe iris whip zoomWipe dotZoom dipFade slideOver clockWipe slices glitch flip lightLeak` و`compare`) تاخذ `A` و`B` كدوال ترسم الإطار كامل. حطها داخل مشهد واحد مكان انتقال المحرّك.
  `glitch` و`flip` يرسمون A/B على الإطار نفسه وياخذون لقطة منه، فأي FX داخل A/B (مثلاً `MV.panel(Y, () => FX.ringStat(MV, t, …))`) يطلع صح.
- الكاميرا (`pushIn pullOut handheld kenBurns snapZoom shake`) تلف `draw`؛ `rackFocus` و`dollyZoom` ياخذون `back` و`front`؛ `parallax` ياخذ `layers:[{draw, depth}]`. بريل الكلام حطها بطبقة `'video'`.
- `lowerThird` تحت يمين داخل المنطقة الآمنة (y ≤ 1500 و x ≤ 920) — لا تحرّكه لزاوية الأزرار.
- `jcut` و`matchCut` قواعد توقيت، مو رسم: J-cut = صوت اللقطة الجاية يسبق صورتها بـ4–12 فريم. القطع المطابق = الشكل نفسه بنفس المكان والحجم على فريم القص.

**بريل الكلام** (`compose.html`): نفس الدوال، بس الـctx اسمه `MV` (من `scripts/moves-compose.js`: أدوات النص والتوقيت وألوان `theme.json` وخطه فوق كانفس المحرّك).
`compose.REFERENCE.html` يحمّل `moves.js` و`moves-compose.js` من مجلد الشغل، و`04_render_frames.js`/`08_safe_check.js` ينسخونهم وحدهم لو ناقصين.
مشاهدك بآخر `compose.html` (بعد سطر التحميل):
```js
MV.ready(() => {                                   // caps.json يوصل بـinit — أي wordTime/lineSpan برّا الرسم داخل ready
  MV.hideCaption(MV.lineSpan(0).s, MV.lineSpan(2).e + 0.5);                 // FX.caption بدال كابشن المحرّك
  MV.scene('cap', t => { const n = [2,1,0].find(i => t >= MV.lineSpan(i).s);   // آخر جملة بدت — الجاية تاخذ مكانها
    if (n !== undefined && t < MV.lineSpan(n).e + 0.5) FX.caption(MV, t, { line: n, y: 1280, out: MV.lineSpan(n).e }); });   // 1 · يقعد بعد صوته ويطلع (6.1)
  const s = MV.wordTime(3, 0).s;
  MV.scene('push', t => { if (t >= s && t < MV.lineSpan(4).e)
    FX.pushIn(MV, t, { s, to: 1.18, focus: [540, 560], blur: false, draw: Y => MV.video(Y) }); }, 'video');   // 12 طبقة الفيديو
  const w = MV.wordTime(5, 0).s - 0.3;
  MV.scene('whip', t => { if (t >= w && t < MV.lineSpan(5).e)
    FX.whip(MV, t, { s: w, A: Y => MV.video(Y), B: Y => MV.panel(Y, () => FX.riseUp(MV, t, { text: 'الفكرة', s: w + 0.35 })) }); });   // 11
});
```
- السطر = رقم الجملة بـ`caps.json` (`MV.wordTime(3, 0)` = أول كلمة بالجملة 3). `line: 0` يشتغل.
- `MV.video(Y, R?)` يرسم فريم الفيديو الحالي (ملء الشاشة افتراضياً) — هو مشهد A/B للانتقالات و`draw` لحركات الكاميرا.
- `MV.panel(Y, fn)` = خلفية الثيم + رسمك: شاشة كاملة بين لقطتين. كابشن المحرّك يبقى فوقها.
- `MV.scene(name, fn, 'video')` لحركة تشتغل على الفيديو نفسه (pushIn/pullOut) فالكابشن يبقى فوقها؛ بدون طبقة = فوق الفيديو وتحت الكابشن.
- ⛔ 6.1 **العنصر ما يختفي مع آخر كلمة:** `out` (بداية الطلعة) = آخر كلمة — و+0.3 لو طلعة الحركة أسرع من 0.4 ث (مثل `speechBubble`) — ونافذة المشهد لين `out + 0.7`. لا تقطع النافذة عند `lineSpan(n).e` (`motion-rules.md` §3).
- ⚠ `FX.caption` بثيم غامق: الحدّ حول الكلمات يصير الأغمق من `ink`/`bg` تلقائياً، والكلمة الحالية بلون `onAcc` فوق الكبسولة.

## 3ط) 103 تحوّل النقاط (من ريل «قبل هالاختبار» — 17 نوفمبر)

مئات النقاط **نفسها** من أول اللقطة لآخرها: تتجمع وتشكّل رقم، تطير بقوس وتشكّل كلمة، ثم شعار، ثم كرت. بلا ولا قطع —

- **الأشكال:** `text` (رقم أو كلمة، العربي جملة كاملة) · `img` (صورة شفافة: شعار، قناع مخ، منتج مقصوص — شفافيتها هي الشكل) ·

- **الوضوح:** الرقم يبي `size` 480 وفوق، والكلمة العربية 400 وفوق وكلمة وحدة أو ثنتين — جملة طويلة بالنقاط ما تنقرا.
  اكتب الجملة نفسها نص عادي فوق أو تحت، والنقاط للشكل بس.
- **اللون:** الخلفية غامقة ← نقاط كريمية تتوهّج، وشكل `hi:true` بلون التمييز. فاتحة ← نقاط بلون الخط بلا توهّج.

- خيارات ثانية: `n` (عدد النقاط 200–1400) · `dot` (حجمها) · `dur` · `stag` · `swirl` (قوس الطيران، 0 = خط مستقيم) · `float` (الرجفة) · `seed`.
- الأصوات (`MV.cue`): `air` مع كل طيران و`tick` لما يكمل الشكل — خفيفة، وزد عليها ضربة بيدك عند أهم رقم.

## 3ي) 104 تيار الخطوط (17 نوفمبر)

آلاف الخطوط الرفيعة تمشي مع **تيار واحد** يتموّج، وبلحظة تنحرف وتتجمع لين ترسم رقم أو كلمة أو شعار — والتيار **يكمل يمشي داخل الشكل**
وعلى حدوده، فالشكل حي مو واقف. بعدها تفلت وترجع تنساب. تنفع عمود لونشوت كامل (التيار خلفية حية والمحطات جمل السكربت) أو لحظة رقم داخل ريل كلام.
- **على النطق:** `at` أو `key` = لحظة **اكتمال** الشكل. التجمع يبدأ قبلها بـ`dur + stag + 0.15` (1.55 ث افتراضياً) — لا تحسبها بيدك.
- **الشكل يقعد `hold`** (1.6 ث) وبعدها يفلت للتيار. لو الشكل اللي بعده يبدأ تجمعه قبلها، الخطوط تروح له مباشرة بلا رجوع للتيار.
- **الأشكال:** `text` · `img` (صورة شفافة) · `box` · `pts` — نفس 103. بلا `shapes` = تيار بس (خلفية حية ورا عنوان).
- **الوضوح:** الرقم يبي `size` 480 وفوق، والكلمة العربية خط عريض وكلمة وحدة — الخط الرفيع ما يشيل خطوط كفاية. `hi:true` يلوّن الخطوط كلها بلون التمييز.
- **اللون:** الخلفية غامقة ← خطوط كريمية تتوهّج. فاتحة ← خطوط بلون الخط بلا توهّج. خط من كل 6 بلون التمييز دايماً.
```js
// ⚠ عرّف الخيارات مرة وحدة (برّا draw أو بـsetup): المسار كله يتحسب أول فريم ويتخزن داخلها
const FL = { s: 0.2, out: 9, shapes: [
  { key: '50', text: '50', size: 640, family: 'num', hi: true },
  { at: 6.4, text: 'أسرع', size: 460, hold: 2 } ] };
ctx.FX.flowLines(ctx, t, FL);                                   // موشن: داخل draw
// ريل كلام: MV.ready(() => MV.scene('flow', t => FX.flowLines(MV, t, FL)));
```
- خيارات ثانية: `n` (عدد الخطوط 300–6000) · `speed` · `dir` (اتجاه التيار: 180 يسار، 270 فوق) · `curl` (تموّجه) · `scale` (حجم الدوامات) · `trail` (طول الخط بالثواني) · `lw` · `swirl` · `seed`.
- ⛔ لا تغيّر الخيارات بين فريم وفريم (المسار مخزّن). تبي تيار ثاني؟ كائن خيارات ثاني.
- الأصوات (`MV.cue`): `air` مع كل تجمع و`tick` لما يكمل الشكل.

## 3ك) 105 قطرات تندمج (17 نوفمبر)

قطرات سائلة بلون الهوية: تنزل من فوق، **تنقسم** (قطرة وحدة ← 3 خيارات) و**تندمج** (رقمين ← رقم واحد). السائل يتمدد بين القطرات وينقطع،
ويهتز شوي لما يستقر. الحافة خط مرسوم (مو غباش)، فتطلع حادة بأي دقة. تنفع لـ«عندك 3 خيارات»، «هذا + هذا = هذا»، «كلهم بواحد».
- **المراحل `stages`:** كل مرحلة = قطراتها. السائل نفسه يتوزّع من مرحلة للي بعدها — 1 ← 3 انقسام، 3 ← 1 اندماج، 2 ← 1 جمع.
- **على النطق:** `at` أو `key` = لحظة ما القطرات **تستقر** وتطلع كتابتها. الحركة تبدأ قبلها بـ`dur` (0.9 ث). بين مرحلة ومرحلة خل 0.9 ث على الأقل.
- **الأماكن:** حدد `x, y, r` لكل قطرة، أو اكتب `texts: [...]` بس وهي تترتب صف واحد (وتصغر لو ما كفّى العرض).
  ⛔ قطرتين بين مراكزهم أقل من 2.4 من نص القطر يلزقون ببعض — باعد بينهم.
- **الكتابة:** كلمة وحدة أو رقم داخل القطرة (تصغر وحدها لو طويلة). الشرح الطويل اكتبه نص عادي برّا القطرة.

```js
// عرّف الخيارات مرة وحدة (برّا draw أو بـsetup)

ctx.FX.liquidDrops(ctx, t, LD);                                 // موشن: داخل draw
// ريل كلام: MV.ready(() => MV.scene('drops', t => FX.liquidDrops(MV, t, LD)));
// رقمين يندمجون: stages: [{ at: 1, texts: ['40', '60'] }, { key: 'مية', drops: [{ text: '100', r: 220 }] }]
```

- خيارات ثانية: `color` و`color2` (أعلى وأسفل التدرّج) · `ink` (لون الكتابة) · `size` · `family` · `wobble` (رجفة السائل، 0 = ثابت) · `glow` · `seed`.
- الأصوات (`MV.cue`): `air` مع بداية كل حركة و`pop` لما القطرات تستقر.

## 3ل) 106 مكعبات تنبني (17 نوفمبر)

مكعبات صغيرة **ثلاثية الأبعاد** تنزل من فوق وتتراص صف فوق صف لين تبني الشكل، وبعدها **تنهد** وتطيح والشكل الجاي ينزل مكانها.
الوجه الأمامي مواجه للكاميرا (الرقم ينقرا عدل) والعمق يبين من فوق ومن الجنب، وزاويته تتأرجح شوي فالشكل يبين مجسم.
- **الأشكال:** `text` (رقم أو كلمة — الخط الافتراضي أرقام عريضة) · `bars` (أعمدة مقارنة: الاسم تحت والرقم يطلع فوق لما يكمل) · `phone:true` (جوال) ·
  `img` (صورة شفافة: المكعبات تاخذ **ألوان الصورة** — شعار بألوانه؛ `tint:true` يخليها بلون الهوية) · `box`.
- **على النطق:** `at` أو `key` = لحظة ما **آخر مكعب ينزل**. البناء يبدأ قبلها بـ`dur` (1.2 ث). بين شكل وشكل خل `dur + 0.4` على الأقل.
- **الوضوح:** `cell` 30 للرقم الكبير (`size` 520)، و22–26 لشعار فيه تفاصيل. أصغر من 20 = مكعبات وايد والشكل يصير صورة عادية.
  الكلمة العربية تبي `family: 'display'` وحجم 420 وفوق وكلمة وحدة.
- **اللون:** تدرّج من `color2` تحت لـ`color` فوق (الافتراضي ألوان الهوية). عمود `hi:true` بلون الهوية والباقي رمادي هادي.

- خيارات ثانية: `depth` (عمق المكعب) · `angle` و`swing` (زاوية العمق وتأرجحها، `swing: 0` ثابتة) · `fall` (زمن نزول المكعب) · `x, y` · `seed`. وللأعمدة: `w`، `h`، `value:false` (بلا رقم فوق)، `text` لكل عمود بدال رقمه.
- ⛔ أرقام الأعمدة من مصدر: العمود يرسم النسبة بالضبط، فلا تحط رقم تقريبي.
- الأصوات (`MV.cue`): `tick` مع نزول الصفوف، `pop` لما يكمل، `air` لما ينهد.

## 3م) 107 صوتك يرسم (17 نوفمبر)

شكل يتحرك مع **قوة صوت المتكلم الحقيقي** مقطع بمقطع — مو حركة عشوائية تشبه الصوت. وسط الشكل = اللحظة الحالية، وأطرافه = اللي انقال قبل شوي
(`span` ثانية)، فالكلمة تمشي فيه مثل موجة والسكتة تبين سكتة. ثلاث أشكال بـ`shape`:
`'ring'` حلقة أعمدة حول قلب ينبض (أو شعار وسطها بـ`img`) · `'bars'` صف أعمدة مثل الرسالة الصوتية · `'line'` خط موجة.
- **ملف الصوت أول:** `python3 scripts/37_env.py <مجلد> --src <ملف الصوت>` يكتب `env.js` (قيمة لكل فريم).
  - ريل كلام: `python3 scripts/37_env.py <work>` (ياخذ `cutz.mp4`) و`<script src="env.js"></script>` بـ`compose.html` — والحركة تلقاه لحالها.
  - فيلم موشن: `python3 scripts/37_env.py <proj>/vo --src vo_full.wav` وبالخيارات `src: '/proj/vo/env.js'`.
  - أو مرّر `levels: [...]` (و`rate` قيمة بالثانية) أو `env: t => 0..1` بيدك.
- ⛔ **بلا ملف صوت الشكل يبقى واقف** على أقل حجم — لا تحركه بأرقام من عندك وتقول «صوته».
- **الصوت يبدأ بنص الفيديو؟** `offset` = ثانية الفيديو اللي يبدأ عندها ملف الصوت.
- **صوت نظيف (مولّد أو استوديو):** قيمه كلها قريبة من 1، فالحركة تفرد الفرق بين المقاطع لحالها. `norm:false` يطفيها.
```js

```
- خيارات ثانية: `w` (عرض الأعمدة أو الخط) · `h` (أقصى ارتفاع) · `n` (عدد الأعمدة) · `span` · `gain` · `color` و`color2` · `core:false` (حلقة بلا قلب) · `glow`.
- ما لها أصوات: هي تمشي مع الصوت نفسه. بريل الكلام حطها تحت الوجه أو جنبه — لا تغطي فمه.

## 3ن) 108 حروف ترسم الصورة (17 نوفمبر)

الصورة تنبني من **حروف وأرقام صغيرة تتبدل** طول الوقت: الفاتح حرف ثقيل (`@ W M`) والغامق حرف خفيف (`. - ~`)، فالصورة تبين من بعيد وهي كلها حروف.
بعدها تمر موجة من الزاوية و**تنكشف الصورة الحقيقية** خانة خانة. تنفع لـ«هذا اللي يشوفه الكمبيوتر»، كشف شعار أو منتج، أو دخلة لقطة.
- **المصدر:** `img` (صورة ثابتة — شفافة أو لا) أو `draw: Y => MV.video(Y)` (رسم حي: لقطة الفيديو نفسها تصير حروف تتحرك معها، وتنكشف للفيديو الحقيقي).
- **على النطق:** `at` أو `key` = لحظة ما **صورة الحروف تكمل** (تبين الصورة). البناء يبدأ قبلها بـ`build + 0.3` (1.4 ث)، والانكشاف يبدأ بعدها بـ`reveal` (0.5 ث) وياخذ `rdur` (0.9 ث).
  `reveal:false` = تبقى حروف (خلفية حية).
- **الوضوح:** `cell` 22 افتراضي. وجه أو منتج فيه تفاصيل؟ 14–18. الصورة لازم فيها فاتح وغامق واضح — صورة باهتة تطلع حروف متشابهة.
  شعار بلون واحد يطلع بنقش هادي بدل الإضاءة (شكله من شفافيته).
- **اللون:** الافتراضي لون واحد (كريمي على الغامق، لون الخط على الفاتح — والفاتح يعكس: الغامق بالصورة هو الحرف الثقيل). `color: 'img'` = كل حرف بلون مكانه بالصورة.

```js
// عرّف الخيارات مرة وحدة (برّا draw أو بـsetup)

ctx.FX.asciiReveal(ctx, t, AS);                                 // موشن: داخل draw
// ريل كلام — لقطته نفسها تصير حروف 1.4 ث وتنكشف:
// MV.ready(() => { const A = { s: 4, out: 7.5, x: 540, y: 960, w: 1080, h: 1920, cell: 20, at: 5.4, draw: Y => MV.video(Y) };
//   MV.scene('ascii', t => { if (t >= 4 && t < 7.9) { MV.X.fillStyle = MV.P.bg; MV.X.fillRect(0, 0, 1080, 1920); FX.asciiReveal(MV, t, A); } }); });
```
- خيارات ثانية: `chars` (حروفك أنت — أي حروف، وترتيب ثقلها يتقاس لحاله) · `flick` (سرعة التبدّل، 0 = ثابتة) · `hi` (لون الحرف وهو ينكتب وينكشف) · `invert` · `h`.
- ⛔ الحروف هني زينة تنقرا شكل مو كلام: لا تحط فيها جملة تبيها تنقرا. وبريل الكلام لا تخلي وجهه حروف أكثر من ثانيتين.
- الأصوات (`MV.cue`): `tick` وهي تنكتب و`air` مع موجة الانكشاف.
