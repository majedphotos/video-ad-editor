# معرض الحركات — المستخدم يختار، وأنت تلتزم

23 حركة مرقّمة (20 من مشاريع مفتوحة + 3 من المحرّك). كل وحدة: معاينة 4 ث + دالة جاهزة بـ`motion/moves.js` + مصدرها.
الهدف: المونتاج ما يكرر حركات المستخدم ما يحبها، وما يحتاج تعديلات كثيرة.

| الملف | شنو فيه |
|---|---|
| `motion/moves/catalog.json` | الرقم · `id` (اسم الدالة) · الاسم العربي · الوصف · المصدر · المعاينة |
| `motion/moves.js` | الدوال: `ctx.FX.<id>(ctx, t, o)` — كل خياراتها مكتوبة فوق كل دالة |
| `motion/moves/index.html` | صفحة الاختيار (يفتحها `scripts/35_moves.py`) |
| `motion/moves/CREDITS.md` | المصادر والرخص |

## 1) الاختيار

- **أول مرة** (بعد صفحة التعارف، أو لما يقول «أبي أختار الحركات» / «ورني الحركات»):
  `python3 scripts/35_moves.py` — يفتح المعرض، ينتظر «احفظ»، ويطبع اختياره. لو المتصفح ما انفتح عطه سطر الـURL.
- **من الشات:** لو رد «أبي 3 و7 و12، و5 لا» ← `python3 scripts/35_moves.py set "3 7 12" --off "5"` (يستبدل الاختيار كله).
- **قبل أي مشهد:** `python3 scripts/35_moves.py show` ← `{"on":[…], "off":[…]}`. ينحفظ بـ`~/.video-ad-editor/profile.json` تحت `moves`.

## 2) الالتزام (إلزامي)

1. ⛔ أي `id` بـ`off` **ممنوع** بأي فيديو له، حتى لو تناسب. لا تسوي نسخة شبيهة منه بكود ثاني.
2. ✅ `on` = حركاته المفضلة: لما تحتاج حركة كلمات/انتقال/كاميرا/كرت، اختر من `on` أولاً من نفس النوع (`cat`).
3. اللي مو بالقائمتين: مسموح، بس لما يخدم معنى الجملة.
4. القاعدة الأقدم ما زالت تمشي: **الحركة من معنى الجملة، مو قالب**. يعني `on` قائمة الأدوات المسموحة، مو قالب يتكرر. لا تحط نفس الحركة على كل جملة.
5. ما اختار شي؟ اشتغل عادي واقترح عليه المعرض مرة وحدة بجملة: «عندي معرض حركات تختار منه بالأرقام، تبي تشوفه؟»

## 3) الاستخدام بالكود

**بمحرّك الموشن** (`motion/` — فيلم الموشن، الونشوت، أي مشهد ينرسم بـ`render.js`): نادِ الدالة مباشرة.
```js
draw(t, lt, ctx) {
  const { X, P, FX } = ctx;
  X.fillStyle = P.bg; X.fillRect(0, 0, ctx.W, ctx.H);
  FX.riseUp(ctx, t, { text: 'الفكرة أهم من الأداة', s: ctx.wordTime('l2', 0).s, accent: [1] });    // 3 طلعة متتابعة
  FX.whip(ctx, t, { s: 4.2, A: Y => drawIntro(Y), B: Y => drawStats(Y) });                         // 11 سحبة
  const tau = FX.ramp(t, { hit: ctx.wordTime('l3', 2).s });                                          // 20 تبطيء الضربة: استخدم tau مكان t
}
```
- الألوان من `ctx.P` (ثيم المستخدم) تلقائياً. لا تمرر ألوان ثابتة.
- `o.s` لازم يكون توقيت كلمة حقيقية (`ctx.wordTime`). `FX.caption` ياخذ `line: 'l2'` ويتزامن مع الصوت كلمة كلمة.
- الانتقالات (`crossZoom softWipe iris whip zoomWipe dotZoom`) تاخذ `A` و`B` كدوال ترسم الإطار كامل. حطها داخل مشهد واحد مكان انتقال المحرّك.
- `jcut` و`matchCut` قواعد توقيت، مو رسم: J-cut = صوت اللقطة الجاية يسبق صورتها بـ4–12 فريم. القطع المطابق = الشكل نفسه بنفس المكان والحجم على فريم القص.

**بريل الكلام** (`compose.html`): هالمحرّك ما يقرا `moves.js` للحين. الاختيار يمشي هني **كقاعدة**:
لا تستخدم حركة شبيهة بأي `off`، ولما تكتب حركة كلمات أو انتقال، قلّد حركات `on` بأدوات `motion-kit` (السلوك موصوف بالكتالوج وبالكود فوق كل دالة).

## 4) إضافة حركة جديدة

1. دالة جديدة بـ`moves.js` بنفس الشكل `FX.<id>(ctx, t, o)`، والألوان من `ctx.P`.
2. سطر بالكتالوج **برقم جديد بالآخر**. ⛔ لا تعيد ترقيم القديم: الناس حافظين أرقام.
3. معاينة 4 ث بنص الدقة: `previews/NN.mp4`، مرسومة من الدالة نفسها، مو من كود ثاني.
4. المصدر بـ`CREDITS.md`، رابط فتحته بنفسك.
