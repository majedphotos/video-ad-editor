# 🎞️ مونتاج داخل كاب كت — مشروع يعدّله بيده بدل MP4

**متى:** قال «سوّه بكاب كت»، «أبي أعدّل بنفسي بكاب كت»، «طلّعه مشروع كاب كت»، وعنده كاب كت ديسكتوب (ماك أو ويندوز).

**شنو يطلع:** مشروع كاب كت كل شي فيه عنصر مستقل يقدر يحرّكه أو يحذفه:

| المسار | المحتوى |
|---|---|
| لقطات | لقطاته والبي-رول، كل وحدة بزوم كيفريمات (داخل/طالع) |
| موشن | بطاقات الموشن بألوانه — ProRes 4444 شفاف فوق اللقطات |
| عنوان + كابشن | نصوص كاب كت حقيقية (يعدّل الكلمة واللون والخط من كاب كت) |
| الفويس | صوته المنظّف، مقطع لكل جملة |
| مؤثرات 1..ن | كل مؤثر مقطع لحاله — يخفضه أو يشيله |
| خلفية صوتية | ملف الصوت بالخلفية بفيد دخول وخروج، يتكرر لو أقصر |

كله بسكربت واحد: `scripts/40_capcut.py` (القالب والموشن والراسم مدمجين فيه).

---

## ⛔ قبل لا تبدأ

1. **مشروع فاضي باسم.** قل له: «افتح كاب كت، سوّ مشروع جديد فاضي سمّه `<الاسم>`، وسكّر كاب كت كامل (Cmd+Q).»
   تأكد إنه موجود: `python3 scripts/40_capcut.py projects`
2. **كاب كت لازم يكون مسكّر وقت الكتابة.** السكربت يرفض لو شغّال — لا تلتف عليه، كاب كت يكتب فوق الملف ويضيع الشغل.
3. **الأدوات:** نفس أدوات السكل (ffmpeg، كروم، puppeteer-core) + ffmpeg فيه `prores_ks` (الموجود بـbrew فيه).
4. **ماك:** كاب كت محبوس بساندبوكس — ما يقرا إلا `~/Movies`. السكربت يحط كل شي بـ`~/Movies/capcut-<name>/` وينسخ له أي ملف برّاها تلقائياً. لا تغيّر هالمسار.

## الخطوات

**1. نفس بداية السكل:** الثيم (`references/start.md`)، خطة القص `01_cut_plan.py`، التفريغ (`a.json`)، التصحيح، و5.5 (اعرض النص وشيل اللي ما يبيه). تحسين الصوت `02b` اختياري.

**2. خطة أولية من فيديو الكلام:**

```bash
python3 scripts/40_capcut.py skeleton <work> <work>/capcut.plan.json
```

مقطع كلام لكل قطعة من `cut.json` بكلماتها من وِسبر، ولقطة فيديو متزامنة لكل مقطع.

**3. اشتغل على الخطة** (الصيغة تحت): صحّح الكلمات (`text`)، الكلمات المميزة (`emph`)، عنوان الهوك، البي-رول بين لقطاته، الموشن من معنى الجملة، المؤثرات، والخلفية الصوتية.

**4. افحص واعرض:**

```bash
python3 scripts/40_capcut.py check  <plan>      # جدول اللقطات والأوقات
python3 scripts/40_capcut.py stills <plan>      # لقطتين PNG لكل موشن بـ~/Movies/capcut-<name>/stills
```

⛔ **اعرض عليه اللقطات وانتظر موافقته قبل الرسم الكامل.**

**5. ابنِ واكتب** (كاب كت مسكّر):

```bash
python3 scripts/40_capcut.py all <plan>         # مؤثرات + رسم الموشن + كتابة المشروع
```

قل له: «افتح كاب كت ← المشروع `<الاسم>` — كل شي فيه تقدر تعدّله.»
دقيقة لكل 50 ثانية تقريباً (الرسم أثقل شي). عدّلت موشن واحد؟ `render <plan> <اسمه>` ثم `write <plan>`.

**الرجوع:** قبل كل كتابة ينحفظ الأصل بـ`~/Movies/capcut-<name>/backup/<الوقت>/` — انسخه فوق مجلد المشروع وكاب كت مسكّر.

**الأوقات بالمراجع، مو بالأرقام** — لو انحذفت جملة كل شي يمشي معاها:

| المرجع | معناه |
|---|---|
| `"S2"` / `"S2>"` | بداية / نهاية مقطع الكلام S2 (أو الوقفة) |
| `"S2:كلمة"` · `"S2:كلمة>"` · `"S2:كلمة#2"` | بداية الكلمة · نهايتها · ثاني مرة تنقال |
| `"+0.2"` / `"-0.05"` بالآخر | إزاحة بالثواني |
| `"end"` · رقم | نهاية الفيديو · ثانية مطلقة |

**الكلام:** `a`/`b` حدود الجملة بالملف (بتوقيت وِسبر)، `off` لو الملف يبدأ متأخر عن وِسبر.
- السكربت يضبط أوقات الكلمات على أول وآخر صوت فعلي (وِسبر يقدّم ويأخّر). عندك الحدود؟ `on`/`end`. ما تبي؟ `"tighten": false`.
- `text` = تصحيح الكلمات بنفس العدد.
- `groups` = كم كلمة بكل كابشن (المجموع = عدد الكلمات). بدونها: 3 كلمات أو 18 حرف، وينقسم عند أي نفَس.
- `{"pause": ث}` = لحظة بلا كلام (كشف صور، نتيجة).

**اللقطات** ورا بعض: كل وحدة لين `to` أو `dur`، والأخيرة لين النهاية.
- `sync: true` = فيديو الكلام نفسه، المصدر يمشي مع الصوت.
- `span` = كم ثانية من المصدر تنضغط بمدتها (يحسب السرعة).
- `fit`: `fill` يعبّي 9:16 (الافتراضي) · `contain` · أو رقم.
- `zoom`: `in` / `out` / `null`.
- الصور (heic/jpg/png) تنحط صورة ثابتة.

**الموشن:** أربع بطاقات جاهزة بألوان ثيمه وخطه وشعاره (`badge` · `roll` · `card` · `endcard`). البطاقة الكبيرة تعدّ الرقم لين قيمته (`25%` يعدّ من 0).
- ⛔ **هذي أساس، مو قالب** — المشاهد تنخترع من معنى الجملة.
- مشهد جديد: صفحة HTML بخلفية شفافة 1080×1920 فيها `window.setup(o)` و`window.render(t)` (t بالثواني من بداية المشهد، `o.marks` أوقات نسبية) ← `"html": "<المسار>"`.

**المؤثرات:** `auto_sfx` يحط ووش+بوب مع العنوان وكل بطاقة. الباقي بيدك بلحظته (مو رش):
`whoosh_up whoosh_down pop thud tap click shimmer sub riser glitch shutter counter`

## حدود معروفة

- القالب من مشروع كاب كت نسخة `183.0.0` (كاب كت 9.x). نسخة ثانية؟ السكربت ينبّه ويكتب. لو ما انفتح، رجّع النسخة الاحتياطية وقل له.
- الكابشن نص كاب كت بحد غامق ولون تمييز من ثيمه — بدون حركات كلمة السكل (الكشيدة، الورا الظهر). يبيها؟ هذا وضع الـMP4.
- كاب كت يعيد حفظ المشروع أول ما يفتحه ويضبط الأوقات على الفريم — طبيعي.
- ويندوز: مجلد المشاريع `%LOCALAPPDATA%\CapCut\User Data\Projects\com.lveditor.draft` (ما فيه ساندبوكس). مو موجود؟ `write <plan> --draft-dir <مجلد المشروع>`.
