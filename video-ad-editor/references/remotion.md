# شاشة التعديل (ريموشن) — المحرّك الثاني

**ابدأ بالخفيف دائماً وبلا كلام.** لا تذكر «ريموشن» ولا «كانفس» ولا «محرّك» ولا تعرض خيارين.
تفتحه بس إذا **هو** قال بعد ما يشوف الإعلان: «أبي أعدّل بنفسي» · «ما عجبني مكان هالشي، أبي أحرّكه» · «فيه شاشة أشوف فيها التعديل؟».
عندها جملة وحدة: «أفتح لك شاشة تعديل مباشرة تشوف فيها الفيديو وتحرّك أي شي وتشوف النتيجة فوراً — تنزيلها ياخذ 5 دقايق مرة وحدة، أبدأ؟»
**ما تعيد أي خطوة سابقة** — القص والتفريغ والكابشن والمؤثرات مشتركة.

| | **الخفيف** (الافتراضي) | **شاشة التعديل** |
|---|---|---|
| التنزيل | صفر إضافي | ~500 ميقا مرة وحدة |
| ما يشوفه | لقطات تعرضها عليه | فيديو حي يسحب فيه ويشوف فوراً |
| الترخيص | حر | شركة بأربعة موظفين فأكثر تدفع (بلّغه إذا كان شركة) |
| الأمر | `04_render_frames.js` | `04b_remotion.sh` |

```bash
bash scripts/04b_remotion.sh <work> setup                     # مرة وحدة — بعد إذنه (~500 ميقا)
bash scripts/04b_remotion.sh <work> studio                    # تايم-لاين حي على المتصفح
bash scripts/04b_remotion.sh <work> render <work>/ad-final.mp4   # MP4 مباشرة بلا فريمات
```
- المشاهد تنكتب بـ`<work>/remotion/src/Scenes.tsx` (نفس المنطق: كل مشهد ياخذ `t`).
- مستطيلات عرض الفيديو بـ`<work>/stage.json` ونصوص الختام بـ`<work>/outro.json`.
- المنطقة الآمنة: `"guides": true` بـ`safe.json` ثم `studio` — تشوف المناطق الحمراء حيّة.
- ما يعرف `R_OFF` بعد.
