# العمق والصوت — كلام ورا وقدام، كاميرا بين الطبقات، كلمة تنوّر المكان، ومؤثرات مربوطة بالحركة (6.5)

من دليل «How I edited my captions reel with AI»، وجرّبناه على ريل بطاريات CUKTECH (النسخة الثانية).
**متى:** ريل كلام فيه لحظات تبيها تبين مجسّمة، أو المستخدم قال «بلا كابشن»، «كلام ورا راسي»، «كلمة تنوّر»، «حرّك الكاميرا».

## 1) الطبقات
الغرفة ← كلام ورا ← أنت (مقصوص) ← كلام قدام. والكاميرا الافتراضية تتحرك حركة خفيفة: القريب يتحرك أكثر من البعيد،
فتبين الكلمات معلّقة بينك وبين الجدار.

```bash
node scripts/11_behind_text.js <work> person <من-إلى>     # القصّ — بيريف نت تلقائياً (حواف شعر ناعمة) · MATTE=apple = قصّ الماك
```
- **القصّ ببيريف نت** (`44_matte.py`): مقارنة ريل البطاريات بزوم على الشعر — قصّ الماك يطلّع هالة من لون الغرفة
  وحافة مدوّرة، وبيريف نت يلحق الشعر نفسه. فوقه **تنظيف لون الغرفة من الأطراف**، فالشخص ينحط فوق أي خلفية أو كلمة بلا هالة.
- ⏱️ بطيء على المعالج: حوالي 13–15 ث للفريم (ثانية كلام ≈ 7 دقايق). قله الوقت قبل، وشغّله بالخلفية، ويكمّل من وين وقف.
  `python3 scripts/44_matte.py <work> <من فريم> <إلى فريم> --check` يقول كم باقي بلا شغل.
- يحتاج مرة وحدة: `pip3 install rembg onnxruntime pymatting` (الموديل ~970 ميقا ينزل أول مرة). ما انصبّ؟ يرجع لقصّ الماك وحده.

`compose.html` ← بعد `moves-compose.js`: `<script src="depth.js"></script>` (04_render_frames.js ينسخه لمجلد الشغل لو ناقص).

## 2) الأوامر (بملف مشاهدك، داخل `MV.ready`)
```js
DEPTH.shot({s:8.57, e:12.88, cam:[[8.57,1.0,0,0],[10.2,1.03,-8,0],[12.88,1.055,4,-2]]});   // [ثانية, زوم, x, y]
DEPTH.word({t:CAPS[3].w[4].s, e:11.4, text:'رقم واحد', at:'back', x:560, y:268, size:150, cue:'hit'});
DEPTH.word({t:…, e:…, text:'كم واط؟', at:'back', y:252, size:160, glow:'#5AA2D2', anim:'slam'});
DEPTH.room({s:12.16, e:12.88, tint:'auto', amt:0.65});      // الغرفة تغمق بلون قريب منها
DEPTH.layer('back', (t,Y,L) => { … });                      // رسمك الخاص بطبقة (شريط عدّاد ورا راسك)
DEPTH.box({s:23.5, e:25.24, quad:t=>TB.at('wh',t), pad:9, dim:0.28});   // مربع على المعلومة (§5)
```
- **وقت الكلمة = `CAPS[n].w[i].s`** — بداية نطقها على الموجة (§4). لا تكتب أوقات باليد.
- `at:'back'` = ورا راسك (جسمك يغطيها) · `'front'` = قدامك. `anim`: pop (الافتراضي) · slam · rise · side.
- `x`/`y`/`light` تقبل دالة بالوقت. المقاسات اللي تعتمد على عرض الخط احسبها **وقت الرسم** مو بـ`MV.ready`
  (الخط العربي ما يكون تحمّل لسا) — شوف `line()` بمثال الريل تحت.
- `person:false` باللقطة = بي رول بلا قصّ: الكاميرا والكلمات بس.

## 3) قواعد الشكل (من تجربة الريل)
- **الكلمة ورا الراس تنكتب فوق الراس، وتحتها يدخل ورا الشعر شوي** — مو بنص الراس. العربي ينقرا غلط لو انخفى حرف من نص الكلمة
  («كم واط» صارت «كـ اط» بأول نسخة). حط y = أعلى الشعر − نص حجم الخط تقريباً.
- الكاميرا بلقطة فيها كلام فوق الراس: زوم ≤ 1.06 (وإلا الكلمة تطلع لمنطقة الأزرار فوق y 150). الدفعة الكبيرة (1.10+) للحظة الضربة بس.
- فرق الغرفة عنك صغير عمداً (أنت تكبر أكثر منها بـ≤3٪ حول وجهك): القصّ يغطي مكانك الأصلي بالغرفة، فما يطلع ظل منك.
  لا تحط إزاحة جانبية كبيرة للقطة فيها قصّ.
- الكلام القدّامي تحت الذقن (y ≈ 1290) — ما ينكتب على الوجه أبداً.
- **بلا كابشن مسموح** لو المستخدم وافق (ماجد 8 نوفمبر: «ما عندكم مشكلة تشيلون الكابشن»): `MV.hideCaption(0, 99)`
  والكلام كله كلمات بالمكان. الكلمة تبقى لين نهاية جملتها (القاعدة 15).

## 4) الكلمة المضيئة تنوّر المكان
`glow:'<لون>'` على كلمة = هالة بلونها + **ضوء بنفس اللون على وجهك وجسمك** (ينقص بشكلك) + **حافة مضيئة من جهتها** + ضوء على الجدار ورا.
- `light: t => …` يخفف الضوء مع الوقت (الكلمة تبقى والضوء يروح).
- مرة أو مرتين بالريل، للحظة الأهم («كم واط؟» بالأزرق، «يصادرونها» بالأحمر). هذي «التوهج بالاسم» المسموح بالقاعدة 16.
- `DEPTH.room({tint:'auto'})` معها: الغرفة تغمق وتاخذ **لون قريب من لونها الأصلي** (`depth.json ← rooms[].bg` من `44_matte.py`)
  أو لون البراند — **ملاحظة ماجد:** يصوّر وخلفيته بلون البراند، فلما نغيّر لون الغرفة نختار لون قريب منها، وأي أثر باقي بأطراف الشعر يذوب.

## 5) مربع بالضبط على المعلومة
```bash
python3 scripts/43_textbox.py <work> wh 23.43 25.23 "90Wh"            # النص المطبوع على المنتج
python3 scripts/43_textbox.py <work> wh 23.43 25.23 "re:/(.{3,5})$"   # القراءة تغلط بالحرف؟ حدّد مكانه من اللي حوله
```
- يقرأ الكتابة بكل فريم (Vision بالماك)، ويطلّع زوايا الكلمة نفسها — مايلة مع المنتج — ويكمّل الفريمات اللي ما انقرت بالتتبّع.
- يطلع `tb.js` (حطه بـcompose قبل مشاهدك) + `tb_<اسم>.jpg` للفحص: **شوفها** قبل الرسم — المربع لازم يلف الكلمة بالضبط.
- بمشهدك: `DEPTH.box({s, e, quad: t => TB.at('wh', t), pad: 9})` — ينرسم بخط يلف حولها مع صوت قلم بطول الرسم.
- `nilError`؟ المحرّك العصبي مشغول بتجميع موديل ثاني — انتظر وأعد.

## 6) سطر كلمات تطلع كلمة كلمة (من ريل البطاريات)
```js
function line(words, o) {            // words = [[نص, ثانية], …] — المكان ينحسب وقت أول رسم (بعد ما يتحمّل الخط)
  let L = null;
  const lay = () => { if (L) return L; X.save(); X.font = (o.weight||700)+' '+o.size+'px "'+FONT+'"';
    const gap = o.size*0.28, ws = words.map(w => X.measureText(w[0]).width); X.restore();
    let xr = (o.x||540) + (ws.reduce((a,b)=>a+b,0) + gap*(words.length-1))/2; L = [];   // من اليمين (عربي)
    ws.forEach(w => { L.push(xr - w/2); xr -= w + gap; }); return L; };
  words.forEach((w, i) => DEPTH.word({ t:w[1], e:o.e, text:w[0], x:() => lay()[i], y:o.y, size:o.size, at:o.at||'front',
    color:(o.hot&&o.hot[w[0]])||'#FFFFFF', cue:(o.cue&&i===0)?o.cue:null }));
}
MV.ready(() => {
  MV.hideCaption(0, 99);
  const W_ = (n, i) => CAPS[n].w[i].s;
  line([['قانون',W_(6,0)],['الطيران',W_(6,1)],['الدولي',W_(6,2)]], {y:1290, size:66, e:14.3});
});
```

## 7) المؤثرات الصوتية — بنك أصوات حقيقية، وكل صوت مربوط بحركة

**الفكرة (من دليل captions reel):** مؤثرات أكثر وأنوع، بس **كل صوت = حركة صارت فعلاً على الشاشة** (كلمة طلعت، خط انرسم،
مربع لف، كاميرا اندفعت) — مو رشّ على كل كلمة (قرار ماجد). وكلها خفيفة وتحت صوته.

### 7.1 البنك
`sfx/bank.npz` — 46 صوت حقيقي برخصة CC0 (ملكية عامة، بلا شرط نسب — المصادر تحت §7.5)، بتسع أنواع:

| النوع | متى |
|---|---|
| `tick` تكّة | كلمة صغيرة تطلع، رقاقة، اختيار |
| `hit` ضربة كلمة | كلمة كبيرة تنضرب (slam) |
| `impact` ارتطام | اللحظة الكبيرة (مصادرة، رفض، انكسار) |
| `air` هواء | دفعة كاميرا، عنصر يطفو بهدوء |
| `swish` سحبة | دخول سريع، كلمة مضيئة، مسحة |
| `whip` سوط (مولّد) | قطع حاد، شي ينقلب بسرعة |
| `pen` قلم يرسم (مولّد) | خط أو مربع ينرسم — **مدته = مدة الرسم** (`d`) |
| `paper` ورق · `pop` · `ding` · `clink` | بطاقة، فقاعة، علامة ✓، معدن |

كل مرة نسخة مختلفة من نفس النوع وبطبقة تتغيّر ±4٪ — فما يطلع صوت آلي يتكرر.

### 7.2 الربط بالحركة
بمشهدك، عند لحظة الحركة نفسها:
```js
MV.cue('pen', o.s + 0.08, { d: 0.47 });     // الخط يبدأ يرتسم هني ويخلص بعد 0.47
MV.cue('hit', W_(1, 2));                     // الكلمة الكبيرة تنضرب
```
ينادى كل فريم عادي (يتسجّل مرة). `DEPTH.word` (بـcue) و`DEPTH.box` و`DEPTH.shot` (الدفعة السريعة) يسجّلون صوتهم وحدهم.

```bash
node scripts/04_render_frames.js <work> cues     # يمر على الفريمات بلا تصوير ويجمعها ← cues.json (دقيقة تقريباً)
python3 scripts/05_sfx.py <work>                 # يخلط cues.json + sfx.json
```
- يدوي بدون مشهد: `sfx.json ← "fx": [[ثانية, "نوع", مدة, قوة]]`.
- الأنواع القديمة (`whoosh_up`, `thud`, `tap`, `counter`…) باقية بـsfx.json كما هي.

### 7.3 تحت صوته دايماً
- القوة الافتراضية خفيفة (tick 0.05 · hit 0.07 · impact 0.09 · pen 0.03).
- **دكنق:** الطبقة الجديدة تنزل ~5 ديسبل وقت ما يتكلم (من صوت `cutz.mp4`) — ما تغطي كلمة.
- الذروة الكلية تحت ‎-18 dBFS (السطر الأخير بـ05_sfx يطبعها). أعلى؟ شيل `sub` أو خفّف القوة.

### 7.4 الكثافة
ريل البطاريات 39 ث: 22 صوت بـ6 أنواع بالنسخة الأولى ← 45 صوت بـ10 أنواع بالثانية، وكلها مربوطة بحركة. الضربات القوية (hit/impact/thud)
بلحظات المعنى بس — والباقي طبقة خفيفة تلحق الحركة. اعرض عليه وين حطّيتها قبل التصدير (القاعدة 1).
