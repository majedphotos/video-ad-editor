# 🎭 «أنت بمكان ثاني وتتكلم بصوتك» — مشهد الأفاتار (مجرّب ومعتمد 28 سبتمبر 2026)

**متى:** يقول جملة فيها مكان ما هو فيه («راح أكون قاعد على مسرح» · «تخيلني بالمكتب») ويبي يشوف نفسه هناك **يتكلم**.
الشكل المعتمد من المستخدم: طقة إصبع ← الخلفية تنقلب مكاناً أبيض، هو قاعد على كرسي بالنص تحت، و**الشرح كله فوقه** بالكود.
التكلفة الفعلية: صورتين 0.08$ + أفاتار ≈ 0.115$/ث (مشهد 6 ثوانٍ ≈ 0.85$). **أقل من دولار للمشهد.**

## الوصفة (3 خطوات، أمرين)
```bash
# 1) الصورة — من فريم وجهه + (اختياري) صورة مرجع للتكوين/الكرسي. خيارين، اعرضهم واختر
python3 scripts/21_avatar_scene.py <work> still 31.3 "He sits relaxed on a modern white armchair in a seamless pure white studio, black trousers and black sneakers." ref_chair.jpg
# 2) الكلام — صوته الحقيقي لنفس المدى بالضبط → أفاتار كلينق → فريمات clips/seat_####.jpg
python3 scripts/21_avatar_scene.py <work> talk 29.20 34.87 <work>/ai/avatar_still0.jpg seat          # يطبع التكلفة بس
python3 scripts/21_avatar_scene.py <work> talk 29.20 34.87 <work>/ai/avatar_still0.jpg seat --yes    # بعد موافقته
# 3) ارسمه بمشهد video-layer (الكود تحت) + nocap بنفس المدى + الشرح فوقه بالكود
```
- **المدى = من لحظة الطقة/التحوّل إلى نهاية آخر جملة بالمشهد** (من `caps.json`). الفريم 1 = لحظة `من` بالضبط → الشفايف على صوته الأصلي (صوت الفيديو يبقى صوت التصوير، مو صوت الموديل).
- الصورة **medium-wide** (راسه عند ~38٪ من الارتفاع): أصغر من كذا الموديل ما يحرّك الفم زين، وأكبر يخرّب «الشرح فوق».

## ⛔ جُرّب وفشل — لا تصرف عليه مرة ثانية
| المحاولة | ليش فشلت |
|---|---|
| Kling image-to-video (O3) بلا صوت | يخترع حركة فم → **يطلع يضحك** («مضحك صراحة») |
| Seedance 2.5 reference-to-video مع الصوت | **يرفض أي وجه حقيقي** (`content_policy_violation · partner_validation_failed`) — لا تجربه لوجه المستخدم |
| صورة مرجع فيها شخص ثاني | الموديل ياخذ **لبس** الشخص المرجع — مرّر المرجع للتكوين بس، واكتب لبسه صراحة بالوصف |
| تصغيره جداً (0.6) | الضحكة/الملامح تختفي بس يضيع إنه يتكلم — 0.72 مع الأفاتار أفضل |
| لقطات «زوايا كاميرا» مولّدة (يمين/فوق) مسرّعة | «صرت كأني أراقوز» — **انشالت نهائياً**؛ لا تقترحها |

## الرسم داخل compose (مشهد طبقة الفيديو)
```js
const SNAP={x:390,y:1010,t:29.20}, END=34.87;               // مكان أصابعه + لحظة الطقة
function seatScene(t){ if(t<SNAP.t||t>=END) return; const im=clipAt('seat',SNAP.t,t); if(!im) return;
  const rv=eio(pr(t,SNAP.t,SNAP.t+0.42));
  X.save(); X.beginPath(); X.arc(SNAP.x,SNAP.y,2300*rv,0,7); X.clip();           // دايرة تنفتح من أصابعه
  const g=X.createLinearGradient(0,0,0,H); g.addColorStop(0,'rgb(236,242,242)'); g.addColorStop(1,'rgb(245,248,247)'); X.fillStyle=g; X.fillRect(0,0,W,H);
  const SC=0.72, dw=1080*SC, dh=1890*SC; X.drawImage(featherClip(im),(W-dw)/2,1600-1570*SC,dw,dh);   // قدماه عند 1600
  seatText(t);                                                                       // الشرح فوقه — كلمات بتوقيت caps.json
  X.restore(); ring(SNAP.x,SNAP.y,2300,rv,ACC,18);                                   // حلقة ذهبية + ومضة بيضا 0.16ث + ثَد بـsfx
}
seatScene.layer='video';
/* featherClip: ارسم الفريم بكانفس جانبي 1080×1890 ثم destination-out:
   - فوق: امسح كل شي فوق y=420 وتدرّج 420→640 (أعلى لقطة الأفاتار فيه تظليل رمادي يطلّع خط)
   - يمين/يسار/تحت: تدرّج 160px — فاللقطة تذوب بالخلفية بلا إطار */
```
- **أخفِ شريط التقدّم والكابشن** بالمدى (`nocap:true` بالمشهد + تجاوز `bar`) — النص فوقه هو الكابشن.
- **الشرح فوقه (y 150–860) بحبر غامق** (`#16161A`) والتمييز بلون الهوية: كلمات تطلع بلحظة نطقها وتتوزع بعرضها المقاس (لا مواضع ثابتة — تتلاصق)، «يتحرك» = كلمات تطير لفوق بأثر، «موشن قرافيك» = حلقات تدور + منحنى بمفاتيح + شريط يتعبّى.
