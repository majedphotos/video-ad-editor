قص شخص عن الخلفية، موشن بطبقات، كابشن، وصوت -14.7 LUFS — والجوال مقفول. استخدمت بدائل من تحت.

## سلّم البدائل (من الأعلى للأدنى)
| الخطوة | الأفضل (ماك محلي) | بيئة بلا ماك / سحابة |
|---|---|---|
| تفريغ الكلام | `mlx-whisper` (الأسرع) ← `whisper` | `faster-whisper` (`pip install faster-whisper`، الموديل من huggingface `Systran/faster-whisper-*`). ✅ اشتغل بجلسة الجوال. |
| قص الشخص عن الخلفية | Vision (`personmask.swift`) | **MODNet** ✅ اشتغل بجلسة الجوال · ثم `rembg` (`pip install rembg`، موديل `u2net_human_seg`) · ثم BiRefNet. ⚠️ الشعر والأيدي أصعب — لا تقص الجزء اللي أصلاً مغطى. |
| تتبع الوجه (قص عمودي، قص الكرت) | Vision (`facetrack.swift`) | MediaPipe أو OpenCV Haar · لو ولا واحد: قص من النص مع تنبيه. (ما انجرّب) |
| تتبع الكف | Vision (`handpose.swift`) | MediaPipe Hands. (ما انجرّب) |
| فيديو آيفون HDR | `hdr2sdr.swift` | `ffmpeg` بفلتر `zscale` + `tonemap=hable` (يحتاج بناء ffmpeg فيه zscale). (ما انجرّب) |
| رسم الموشن فريمات | puppeteer + كروم | كروم/كروميوم بلا واجهة (headless) + ffmpeg ✅ اشتغل بجلسة الجوال · أو playwright (`npx playwright install chromium`). |
| تنزيل موديلات | عادي | لو دومين محجوب جرّب بديل (huggingface أو github releases). لو الاثنين محجوبين: قل للمستخدم بالاسم أي دومين، ولا توقف الشغل — كمّل بالخطوات اللي ما تحتاجه. |
| صفحة التعارف (ألوان/خط) | تفتح بالمتصفح | بلا متصفح: سؤال واحد بالشات عن الألوان |

⛔ ما تخترع أداة. كل بديل فوق إما ✅ مجرّب فعلاً بجلسة ماجد أو مكتوب «ما انجرّب» — اللي ما انجرّب جرّبه بجملة وحدة قبل ما تبني عليه.

## قواعد الجودة اللي ما تتغير بالبيئة
- بعد أي قص: قارن الحافة (الشعر، الأيدي، تحت الكادر) على 3 لقطات صعبة قبل ما ترسم كل الفريمات.
- «الكلام ورا الشخص»: الكلمة تتمدد بكشيدة عشان ما تنقص ورا الراس (`references/cut-styles.md`).
- الانتقال بين المقاطع سريع (≈ ثلث ثانية)، مو بطيء.
- الجزء المغطى من الجسم ما يحتاج قص.
- صوت -14 LUFS (`06b_master.sh`).
- لا تسلّم بلا لقطات فحص، وقل بصراحة شنو شفت وشنو ما شفت.

## الجوال: كيف يمشي الشغل
1. المستخدم يرفق الفيديو ويكتب طلبه بجملة.
2. تشتغل بالخلفية، والجوال يقدر يقفل — تخبره إن النتيجة بتنتظره بنفس المحادثة.
3. ترسل mp4 + ملخص: شنو تغيّر، شنو بدّلت، شنو ما فحصته.
4. ملاحظاته (مثل «القص يخرب الشعر») تعدّلها بدون إعادة تصوير.
