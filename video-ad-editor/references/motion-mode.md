# شرح بالموشن — فيلم من نص

المدخل: نص، أو فكرة، أو سكربت.
الطريق: صوت (صوته، أو مولّد مجاني) ← فيلم موشن ثلاثي الأبعاد بـ60 فريم.

الخطوات والأوامر ← `motion/README.md`، ثم دليل كاتب المشاهد `motion/ENGINE-API.md`.

---

## ⛔ وكيل واحد يبني الفيلم كامل

- برومبت واحد، بلا فريق ولا حكّام ولا نقّاد — إلا لو طلب «لمّعه».
- تجربة 28 سبتمبر: وكيل واحد 22 دقيقة ← «خطير». فريق 13 باني + نقّاد ← 6 ساعات.

## سقف الجودة

برومبت المستخدم حرفياً:

> Craft a high-energy motion graphics piece that flexes your top-tier animation skills
> like a killer portfolio reel. Pull out all the stops, like the creative work on Dribbble, fps 60

يعني: ثلاثي أبعاد، ورسم خط، وحروف عربية تتحرك. عين ما ترمش.

## لا قالب

- اعصف 3 أفكار بنفسك، انقدها، وطوّر الأقوى.
- كل جملة تنشاف بلحظة ما تنقال.

## الرتم

- جملة ≈ مشهد.
- ضربة أو تغيير كل 0.5-1 ث.
- بس أي كلمة على الشاشة تبقى 0.6 ث على الأقل عشان تنقرا.
- لا تقصّ الفراغات لين يصير لاهث.

## الصوت المولّد

- فصحى مشكّلة كاملة — اللهجة بالأصوات المجانية مكسّرة.
- تاء مربوطة آخر الجملة ← «ه» بنص الصوت.
- لا ألف خنجرية.
- الاسم الإنقليزي بحروفه (Opus).
- راجع كل سطر بعينك وبوِسبر medium **قبل** الرسم.
- أرسل له الصوت يسمعه.

## الصوت بالفيلم

- الكلام + مؤثرات صوتية بس.
- ⛔ بلا ملف صوتي بالخلفية افتراضياً — اللي يبي خلفية يضيفها بنفسه:

```bash
python3 motion/audio.py <المشروع> --no-bed
```

## سلّم مسودة بدري

ورقة لقطات أو نص الجودة — قبل الرسم الكامل.

## شرح موقع أو تطبيق

يعطيك رابط موقع، أو يقول «اشرح للناس شلون يسوون كذا بالتطبيق».
الناتج: لقطات حقيقية داخل إطار جوال أو كمبيوتر مرسوم.

يصوّر الموقع (شاشات + تمرير + نصوصه وألوانه):

```bash
node scripts/27_web_capture.js <url>
```

ديمو بآيفون أو ماك بوك **ثلاثي الأبعاد حقيقي** (معدن وزجاج وظل، يلف ويقرّب على الزر):

```bash
node scripts/31_device3d.js
```

نسخته المسطّحة السريعة: `scripts/30_demo.js`

التفاصيل كلها ← `references/web-app-explainer.md`
