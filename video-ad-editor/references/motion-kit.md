# حزمة الموشن `motion-kit.js` — مستوى الشوريلز داخل هويتك (v3.6)

**ليش:** بعد مشهد إثبات أرقام ريل «نقول وداعاً لتعديل الفيديو؟» (27 سبتمبر 2026) قال المستخدم: «ايوااا كده من زمان… نبي الحركة الديناميكية هذي سواء لما أتكلم وأصير نص الشاشة، أو كرت صغير تحت، أو لما أختفي… ابي إبداع ماله حدود».
الحزمة = مكوّنات جاهزة بجودة عالية تركب على **نفس المحرّك ونفس الأوضاع** (R_DOWN · R_LOWER · R_OFF) — مو محرّك مواز.

## التحميل
```bash
cp scripts/motion-kit.js <work>/
```
وبـ`compose.html` تحت سكربت المحرّك وقبل سكربت مشاهدك: `<script src="motion-kit.js"></script>`

## الصناديق حسب الوضع
| الوضع | الصندوق `box` | ملاحظة |
|---|---|---|
| `R_DOWN` (أنت بالنص) | داخل `panelIn(t,s,e,()=>…)`: `{x:130,y:278,w:820,h:180}` | يتكبّر 1.2 وحده — مكوّن واحد بسيط (كاينتك، ختم، خانة تعليق، عدّاد صغير) |
| `R_LOWER` (كرت صغير تحت) | `{x:60,y:170,w:960,h:1150}` | المساحة الكبيرة: شبكة بطاقات، تايملاين، مقارنة أعمدة |
| `R_OFF` (بدونك) | `{x:60,y:170,w:960,h:1400}` | الشاشة كلها: `techFrame` + عدّاد ضخم + منحنى + بطاقات |
| `R_FULL` (ملء الشاشة) | فوق الفيديو مباشرة | `stamp` أو `kinetic` قصير بس — لا تغطي الوجه |

## المكوّنات
| الدالة | وش ترسم | أهم الخيارات |
|---|---|---|
| `MK.odometer(t,o)` | رقم بعجلات يركض ويخبط + انفجار نقاط | `s, dur, val, cx, cy, size, prefix, suffix, slam` |
| `MK.shake(t,s)` | إزاحة الرجّة لحظة الخبطة `[dx,dy]` | لفّ رسمك بـ`X.translate(dx,dy)` |
| `MK.burst(t,o)` | انفجار نقاط من نقطة | `s, cx, cy, spread` |
| `MK.statCard(t,o)` | بطاقة تنبثق بزنبرك وتعدّ رقمها + رسمة صغيرة | `label, val, format:'k'|'comma', prefix, bg, ink, viz:'ring'|'bars'|'avatars'|'bubbles'|'spark'` |
| `MK.statGrid(t,o)` | بطاقة كبيرة + 4 صغار بتتابع | `hero:{…}, cards:[…]` |
| `MK.lineChart(t,o)` | منحنى يرتسم + تعبئة + نقطة تنبض | `points:[0..1]|'hockey'|'steady', max:'1M'` |
| `MK.compareBars(t,o)` | أعمدة مقارنة (قبل/بعد) بأرقامها | `items:[{l,v,u,hot}]` |
| `MK.kinetic(t,o)` | كلمات عربية تطلع من قناع (أو تخبط) | `words, hot:[i], mode:'rise'|'slam', times:[…], underline` |
| `MK.techFrame(t,o)` | إطار تقني: زوايا + تايم كود + مسطرة | `title, sub` |
| `MK.timeline(t,o)` | تايملاين مونتاج + ماسات + رأس تشغيل + زر «رندر» | `steps:[…], clickAt` |
| `MK.commentBox(t,o)` | خانة تعليق تنكتب بنفسها + إرسال ينبض | `text, cps` |
| `MK.stamp(t,o)` | ختم مزدوج ينطبع مايل + موجة | `text, cx, cy, rot` |
| `MK.iconArray(t,o)` | شبكة أيقونات بشر «X من كل N» تتعبّى والمظلّلين يتلوّنون | `total, hot, cols, hotAt, pick` |

كل مكوّن: `o.s` بداية (اربطها بالكلمة: `wordsOf(i)[j].s`)، و`o.e` نهاية اختيارية (تلاشي 0.25ث).

## مثال — جملة «ريل واحد جاب قريب مليون مشاهدة» بوضع R_OFF
```html
<script src="motion-kit.js"></script>
<script>
SCENES=[{s:0,e:3.2,m:R_FULL},{s:3.2,e:8.6,m:R_OFF,nocap:true},{s:8.6,e:99,m:R_FULL}];
function viewsScene(t){ if(t<3.2||t>8.6) return; const w=wordsOf(1), hit=w[3].s;      // «مليون»
  MK.techFrame(t,{s:3.2,e:8.6,title:'إحصائيات ريل'});
  const [dx,dy]=MK.shake(t,hit+1.4); X.save(); X.translate(dx,dy);
  MK.odometer(t,{s:hit-0.5,dur:1.9,val:963007,cx:540,cy:640,size:170,e:8.6});
  MK.lineChart(t,{s:hit+1.2,dur:1.2,box:{x:110,y:780,w:860,h:420},max:'1M',e:8.6}); X.restore(); }
SCENE_LIST.push(['viewsScene',viewsScene]);
</script>
```
وبـ`sfx.json`: `"counter":[[البداية, 1.9]]` (تكات تتسارع وتتباعد مع العدّاد) + `"thud":[لحظة الخبطة]` + `"tap":[لحظات انبثاق البطاقات]`.

## ⛔ الحزمة أساس مو قالب (أمر المستخدم 27 سبتمبر)
«ما أبي تكون محدود بالحركات اللي أضفتها بحيث تكون متكررة… أنت عندك علم الموشن قرافيكس والإنفوقرافيك وتقرر شنو يحتاج المشهد».
المكوّنات فوق = مفردات جاهزة. **كل جملة تُصمَّم من معناها** — ابنِ فوق المكوّن، اكسره، أو ارسم شي جديد كلياً بالكانفس. ممنوع نفس المشهد بفيديوهين.

### جدول القرار: نوع المعلومة ← الشكل
| يقول | نوع المعلومة | الشكل الإنفوقرافيكي (أمثلة — مو حصر) |
|---|---|---|
| «4 من كل 100 يصابون» | جزء من كل | شبكة 100 أيقونة و4 تنور (`iconArray`) · 100 نقطة تتبعثر و4 تتجمع |
| «النص تقريباً» / 38% | نسبة | دونات تتعبّى · كوب يمتلي لين الخط · شريط ينشق |
| «زادت / نزلت» | اتجاه | منحنى يرتسم · سهم يطلع وينكسر · درج يصعد |
| «أكثر من / أقل» | مقارنة | عمودين · كفتين ميزان · دائرتين بحجمين |
| «الأول، الثاني…» | ترتيب | سباق أعمدة · منصة تتويج · قائمة تنقلب |
| «تصوّر ← ترفع ← تنشر» | عملية | خط زمن بخطوات · أسهم تتسلسل · تايملاين |
| «بـ3 ثواني / كل يوم» | زمن | ساعة تلف · عدّاد تنازلي · تقويم يتقلب |
| «بالكويت / الخليج» | مكان | خريطة مبسطة ودبوس ينزل · موجات من نقطة |
| «100 دينار / مليون» | مال | عملات تتكدس · فاتورة تنطبع · رقم يخبط |
| «لأن / فصار» | سبب ونتيجة | دومينو يطيح · ترس يلف ترس · سلسلة تنكسر |
| «خطأ / خلل» | مشكلة | قليتش + شقوق · علامة ✕ تخبط · شاشة تسوّد |
| اقتباس / جملة قوية | رسالة | كاينتك تايبو بالكشيدة · كلمة تتمدد · نص ورا الراس |

### لوحة الأصوات (`sfx.json`) — صوت لكل حدث بصري
| الحدث | المفتاح | الصيغة |
|---|---|---|
| عنصر يدخل / ينتقل | `whoosh_up` · `whoosh_down` · `soft` | `[ثانية]` · `[[ثانية, قوة]]` |
| عدّاد يركض | `counter` | `[[بداية, مدة]]` |
| خبطة رقم / لحظة كبيرة | `thud` + `sub` | `[ثانية]` |
| قبل كشف مهم | `riser` | `[[لحظة الكشف, مدة]]` (ينتهي عليها) |
| بطاقة / فقاعة تطلع | `pop` | `[ثانية]` |
| زر / اختيار / أيقونة تنور | `click` · `tap` | `[ثانية]` |
| نص ينكتب | `type` | `[[بداية, مدة]]` |
| تظليل كلمة / لمعة | `shimmer` | `[ثانية]` |
| خطأ / انكسار | `glitch` | `[ثانية]` |
**الصمت أداة:** شيل كل الأصوات نص ثانية قبل الجملة الأهم. ≤ 15 حدث بالدقيقة (التكات لحظة وحدة).

## قواعد الإبداع (لا تكسرها)
1. **الرسمة دليل على الكلمة مو زينة** — يقول رقم ← عدّاد يخبط على نفس الكلمة؛ يقول «زاد» ← منحنى؛ يقارن ← أعمدة؛ يعدّد ← بطاقات بتتابع؛ يطلب تعليق ← خانة تعليق. اعصف 3 أفكار لكل جملة واختر أقواها.
2. **بطل واحد بالمشهد** — مكوّن رئيسي واحد + مساند واحد على الأكثر بـ`R_DOWN`؛ `R_LOWER`/`R_OFF` يستحملون شبكة.
3. **الخبطة على الكلمة المنطوقة** — `dur` العدّاد ينتهي على `w.s` الكلمة (الرقم نفسه)، والرجّة والانفجار والصوت بنفس الفريم.
4. **أرقام حقيقية فقط** — من المستخدم أو من مصدر؛ لا تخترع رقم عشان تستعمل العدّاد.
5. **الهوية ثابتة** — ألوان `theme.json` (ACC/INK/BG/CLAY)، خط المحرّك، الشبكة؛ الحزمة تقرأها تلقائياً.
6. **المنطقة الآمنة وقاعدة الكابشن كما هي** — `R_OFF` بلوحة فيها النص → `nocap:true`؛ لا نص تحت y 1500 إلا الكابشن.
7. **الإيقاع** — كل مكوّن يثبت ≥ 1.2 ث بعد ما يكتمل؛ المؤثرات على اللحظات بس (≤ 15 بالدقيقة، التكات تنحسب لحظة وحدة).
8. **عاين قبل الرسم الكامل** — ورقة 6 لقطات (الخطوة 7) ولقطة وحدة عند كل خبطة.
