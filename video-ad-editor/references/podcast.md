# وضع البودكاست — كاميرتان أو أكثر (v2.7)

كاميرتان (أو أكثر) لنفس الجلسة → ريل 9:16 واحد. ماك فقط (الوجوه وقصّ الشخص بمكتبة Vision). **أمران بس** — كل شي بينهما آلي:

```bash
python3 scripts/15_podcast.py prep <work> <مجلد الكاميرات | ملف1 ملف2 …>
#  يزامن الكاميرات بالصوت · يفحص العطب بكل كاميرا (نصف كادر أسود مثلاً) ويستبعده وحده
#  يرصد الوجوه والفم → من يتكلم متى · هل الكاميرتان لنفس الشخص؟ · يفرّغ الكلام ويطبعه مرقّماً
#  (يطلّع الفريمات بالتوازي — 3-5 دقايق لفيديو دقيقة)
#  ← صحّح النص بـfixes.json (نفس صيغة وضع الكلام: عدد الكلمات لازم يساوي، الكلمة المحذوفة = "")
python3 scripts/15_podcast.py make <work>
#  كابشن · خطة مشاهد · قصّ الراس · رسم · تجميع · معايرة · srt · ورقة لقطات sheet.jpg
```

## الأوضاع الأربعة (يخطّطها السكربت بنفسه، بإيقاع هادي)

| الوضع | متى | الشكل |
|---|---|---|
| `FULL` | المتكلم يتكلم | كاميرته ملء الشاشة (وزوم خفيف 1.08 بالتكرار) |
| `FULL` للثاني | يردّ عليه | كاميرته ملء الشاشة |
| `SPLIT` | حوار سريع، أو كل ثالث تبديل | المتكلم فوق والثاني تحت بخط بلون التمييز |
| `HEAD` | جملة فيها رقم أو كلمة ساخنة (مرة أو مرتين) | كرت صغير تحت وراسه طالع فوق حافته، والكلام قصاصات كولاج فوق — بلا كابشن |

**نفس الشخص بزاويتين؟** (يكتشفه من تطابق حركة الفم) → ينوّع بالزاوية: القريبة (الوجه الأكبر) بالهوك، ثم قريبة/مقسّم/واسعة/زوم بالتناوب.
**قواعد الإيقاع:** الهوك ملء الشاشة بالقريبة · ما يبدّل قبل 4 ثوانٍ · ما يطوّل فوق 9 · مشهد `HEAD` 3-8 ثوانٍ وبينهما 8 على الأقل.

## الثيم
`theme.json` بمجلد الشغل (أو بمجلد الكاميرات وينسخه) — نفس مفاتيح وضع الكلام + `capStyle: "shadow"` (نص أبيض بظل بلا خلفية، كلمتين-ثلاث، الكلمة المنطوقة بلون التمييز) أو `"card"` · `fontFiles` لخط محلي (`[{src, weight}]`) · `logo` · `site`. **الألوان من الشخص نفسه (الخطوة 1) — ما فيه ثيم افتراضي.** الأرقام غربية دائماً حتى لو الخط يرسمها هندية.

## 🪝 الهوك المكتوب (v3.8.1 — إلزامي لكل ريل)
كل ريل يبدأ بجملة هوك **مكتوبة** على الشاشة 1.5-3 ث (مو أول جملة قالها — من أقوى سطر بالمقطع)، والمقطع يشتغل تحتها، ثم يطلع ويرجع الكابشن.
```bash
python3 scripts/22_hook.py suggest <work>                       # أقوى السطور + الأرقام المسموحة
python3 scripts/22_hook.py check <work> "هوك 1" "هوك 2" "هوك 3"  # 3-8 كلمات · أداة شد · لهجة · الرقم من كلامه
python3 scripts/22_hook.py apply <work> "الهوك" [--kicker "اسم البودكاست"] [--style card]
python3 scripts/22_hook.py preview <work>                       # hook_sheet.jpg — اقراها قبل الرسم الكامل
```
`16_render_pod.js` يركّبه وحده لو `theme.json ← hook` موجود — ويحط الهوك على الفاصل بـSPLIT، وفوق على الورقة بـHEAD، ويطفي «السؤال الكبير» وكولاج الكلام وقته. طبّق الهوك **قبل** `plan` عشان السؤال الكبير يختار سؤالاً بعده. القواعد والصيغ: `references/podcast-hook.md`.

## بعد `make`
- اقرأ `sheet.jpg` وحدها واعرضها عليه.
- تعديل مشهد؟ عدّل `plan.json` ثم `node scripts/16_render_pod.js <work> range <من> <إلى>` وأعد التجميع من `make` (يكمّل بلا إعادة القصّ).
- تعديل نص؟ `fixes.json` ثم `make`.
- **ما ينقص السكتات** (الحوار طبيعي فيه وقفات) — لو طلبها، `10_script_edit.py drop` يشيل جملاً كاملة.
- **ملفات المخرج:** `pod-master.mp4` · `pod-master.srt` · `pod-master.txt` · `sheet.jpg`.
- التسليم: اذكر عدد الكاميرات وفرق المزامنة وأي عطب استُبعد.

الملفات: `15_podcast.py` · `16_render_pod.js` · `compose.PODCAST.html` · `facetrack.swift` · `22_hook.py` + `hook-card.js`.

## 📺 الحلقة كاملة بالعرض 16:9 (يوتيوب) — مو ريلات
المدخل نفسه (مجلد ملفات الكاميرات الخام، ومعهم ملف المايك لو منفصل واسمه فيه audio/mic/zoom/rode)، والمخرج حلقة كاملة 1920×1080 تتنقّل بين الكاميرات حسب مين يتكلم:
```bash
python3 scripts/24_podcast_wide.py prep   <work> <مجلد_الكاميرات>     # مزامنة بالصوت + الصوت الرئيسي + وجوه وفم (ساعة ≈ دقايق)
python3 scripts/24_podcast_wide.py plan   <work>                      # edl.json + سطر ملخص (عدد اللقطات، نسبة كل كاميرا)
python3 scripts/24_podcast_wide.py render <work> --preview 90         # معاينة أول دقيقة ونص — وريه قبل الكامل
python3 scripts/24_podcast_wide.py render <work>                      # episode-wide.mp4 بصوت ‎-14 LUFS
```
- **الكاميرات:** اللي فيها شخصين أو أكثر = «واسعة» (الافتتاحية، السكتات وتداخل الكلام، ولقطة 4 ث كل 45 ث داخل الكلام الطويل). الباقي «قريبة» وتنتقل لمين يتكلم بعد ما يستمر كلامه ثانية (ما تنط على «إي» و«صح»)، وأقصر لقطة 2 ث (`--min`، `--wide-every`).
- **كاميرا جوال طولية؟** تنعرض بنص الكادر على خلفية مغبّشة منها — بدون مغط.
- **ما عرف مين يتكلم** (نفس الشخص بكل الكاميرات أو وجوه مو واضحة) ← يطبع تنبيه ويبدّل عند السكتات كل 6-12 ث.
- **ما فيه قص سكتات ولا كابشن افتراضاً** — الحلقة مثل ما انقالت. يبي يشيل مقطع؟ عدّل `edl.json` (احذف اللقطة وزحزح) أو قصّ الناتج بـffmpeg.
- **الريلات من نفس الحلقة:** `cams.json` و`master` جاهزين — كمل بقسم «حلقة كاملة ← عدة ريلات» بـ`references/landscape.md`.
- مجرّب 2 أكتوبر على 3 كاميرات صناعية من حلقة (وحدة متأخرة 2.3 ث، وحدة طولية): المزامنة طلعت بالضبط (+2.30 / ‎-1.00)، و29 لقطة بـ3 دقايق. **ما انجرّب على تصوير حقيقي بكاميرتين لشخصين** — أول حلقة: شيّك المعاينة بعينك.
