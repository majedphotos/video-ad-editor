# 📱 الاستوديو (v3.1) — جوال أو متصفح

**متى تفتحه؟** لما يقول «أبي أعدّل بنفسي» · «عطني التايملاين» · «أبي أغيّر ستايل الكابشن» — أو بعد أول تسليم لو عنده تعديلات صغيرة كثيرة (أرخص من إعادة كل شي بالمحادثة).
⚠️ الخادم يفتح على الشبكة المحلية (نفس الواي فاي) بلا كلمة سر — لا تشغّله على شبكة عامة.

```bash
python3 studio/studio.py <work> [port]      # يطبع رابطاً تفتحه بجوالك على نفس الواي فاي (البورت الافتراضي 8792)
```

تايم لاين باللمس فوق نفس المحرّك ونفس الراسم (صفر توكنز لكل تعديل). فيه:
- التحكم بالقص (رجّع أو اقصّ السكتات، احذف مقطعاً أو جملة — يعيد البناء ويحوّل كل الأزمنة)
- 6 ستايلات كابشن (`references/word-fx.md`) · مؤثر على أي كلمة (طيحة · اهتزاز · كتابة · نبضة)
- «ورا الراس» بضغطة · مؤثر صوتي عند الجملة
- رفع بي-رول من الجوال (ملء الشاشة أو كرت فوق) · المشاهد الأربعة + الكولاج
- الهوية · مناطق أمان انستقرام · قبل/بعد · رابط للعميل يعلّق على أي ثانية (`/share`) · التصدير من الجوال

التعديلات تُحفظ بـ`studio.json` (+caps/theme/sfx) وتنعكس بأي رسم لاحق — `04_render_frames.js` و`08_safe_check.js` يقرونها.
المسافة = تشغيل/إيقاف · الأسهم = فريم · Shift+سهم = ثانية.

## مفاتيح `studio.json` اللي يقرأها المحرّك
`scenes` (`[{s,e,m:"R_FULL"|"R_DOWN"|"R_LOWER"|"R_OFF"|"R_COLLAGE",nocap?,gb?}]`) · `stickers` · `brollClips` + `brNeed` · `behindOff` · `outro` (`l1,l2,chips,cta,word`) · `gen` + `genFrames` (`references/gen-scenes.md`) ·
`sceneFx`: أسماء دوال مشاهد مكتوبة بـcompose.html تتسجّل بـ`SCENE_LIST` (مثال `["myPanel"]`) — **افتراضياً ما فيه أي مشهد مخصص**؛ `false` يفرّغ القائمة.

## الاستوديو القديم (سحب على التايم-لاين)
`scripts/studio.html` صفحة قديمة فيها مشاهد المثال — للمرجع:
```bash
cp scripts/studio.html <work>/ && python3 -m http.server 8791 --directory <work>   # ثم /studio.html
```
