# بنك الستايلات — اللغة البصرية للفيديو كله

الحركات (`references/moves.md`) تجاوب **«شلون يتحرك»**. الستايل يجاوب **«شلون يبين»**: السطح، الملمس، الخط، شكل الكرت، الملصق، وشخصية الحركة.
نفس حركة «الطلعة المتتابعة» تطلع ورقية بستايل الورق، ونظيفة ناعمة بالكينوت.

| الملف | شنو فيه |
|---|---|
| `motion/styles.js` | 17 ستايل (توكنز) + السطوح والكروت والملصقات والتواقيع · `STYLES.make(spec)` |
| `motion/styles/catalog.json` | مولّد منه (`node motion/styles.js --catalog`) — يقراه `35_moves.py` |

## 1) الستايل يجي مع لوحة الفيديو

`python3 scripts/35_moves.py plan …` يطلّع الحين **`style`** مع العائلة والحركات (اختيار يناسب العائلة واللحظات، وما يتكرر ورا بعض، وثلث الفيديوهات تطلع **دمج** `a+b`).
- `--style auto` (الافتراضي) · `--style paperCut` · `--style explainer+keynote` · `--style none` (ثيم المستخدم بس).
- `moments` = ستايل لحظة (VHS، بروتالي) للهوك أو الطلب **1–3 ث بس**، مو للفيديو كله.
- قل للمستخدم بسطر: «لوحة هالفيديو: ورق مقصوص — طلعة متتابعة + سحبة + إشعارات».

## 2) ⚠️ لغة مو قالب — هذا أهم سطر

الستايل **مفردات** تعبّر فيها، مو شكل تنسخه. القوي فعلاً:
- **ادمج:** `A+B` = السطح والملمس والكرت والشخص من A، والخط والحركة والملصق من B. (لا ملمسين ولا خطين display.)
- **خذ جزء:** سطح الوثائقي بس مع كروت الكينوت، أو ختم الوثائقي لحظة وحدة داخل فيديو ورقي.
- **اخترع من معنى الجملة:** «قبله أفكار موجودة أصلاً» = جدار مليان أفكار فوق الراس. الستايل يعطيك الملمس، والفكرة من الجملة.
- لا تحشي كل تواقيع الستايل بفيديو واحد — 2–3 لحظات توقيع تكفي، والباقي كابشن نظيف.

**`needsCut`** (كينوت، شرح صحفي، ورق، مجلة، سويسري، ريزو، جريدة، بلوبرنت، ستوديو، ستيكر، كرت أداة): السطح يبدّل خلفية الفيديو — يحتاج قصّ الشخص (ماك). برّا الماك أو بلا قصّ: الستايل يطبّق ألوانه وخطوطه وكروته فوق الفيديو العادي بدون ما ينكسر.
**لون الهوية:** الستايل ياخذ `acc` من ثيم المستخدم، إلا اللي لونه جزء من هويته (`lockAcc`: شرح صحفي، وثائقي، ريزو، سويسري، تيرمنال، VHS، بلوبرنت، بروتالي، جريدة).

## 4) بالكود

**فيلم الموشن** (`motion/` · `render.js`): `project.json` ← `"style": "paperCut"` → ألوان المشروع وخطوطه من الستايل، و`ctx.S` جاهز:
```js
draw(t, lt, ctx) {
  const { X, S } = ctx;
  S.background(X, t, { video: Y => drawVideo(Y), person: Y => drawPerson(Y), behind: Y => S.label(Y, 'بالكامل', 540, 720, { k: S.ease((t - 0.4) / 0.5) }) });
  S.label(X, 'مبني على شغل', 540, 1500, { k: S.ease((t - 2) / 0.4), tape: true });   // ملصق بتوقيع الستايل
  S.sig.tape(X, t, { x: 300, y: 1440 });   // التواقيع: tape pin string typewriter redact arrow code tag breadcrumb mascot bubble dimension shake spin
  S.post(X, t);              // الملمس الأخير (حبيبات/فينيت)
}
```
**ريل الكلام** (`compose.html`): مرة وحدة فوق مشاهدك:
```js
const S = MV.useStyle('explainer+keynote');            // MV.P وخطوط display/body/num تصير من الستايل
MV.scene('s', (Y, t) => {
  S.background(Y, t, { video: y => MV.video(y), person: MV.person.ok() ? y => MV.person(y) : null });
  S.label(Y, 'الرقم', 540, 420, { k: S.ease((t - 3.1) / 0.5) });
  S.post(Y, t);
});
```
- `S.label(X, نص, x, y, {k, size, color, bg, rot, seed, …})` — `k` = تقدّم الدخول 0..1 (مرّره من `S.ease`). كل ستايل له ملصقه (slap/stamp/highlight/chip/notif/…)، و`{kind:'stamp'}` يستعير ملصق ستايل ثاني.
- `S.card(X, x, y, w, h, {kind})` · `S.text(X, نص, x, y, {role:'display'|'body'|'num'|'accent'|'hand'})` يرجّع العرض.
- `S.tq(t)` = الوقت «على اثنين» للستايلات اللي فيها `fps` (ورق، ستيكر) — استخدمه للحركة عشان تحس ستوب موشن.
- الأرقام غربية، والعشوائية ثابتة (`S.rng(seed)`)، والكلمة العربية ما تنقسم حروف.

## 5) الرخص

كل الرسم بالكود (بلا أصول خارجية). الخطوط من `motion/fonts` (OFL). **ممنوع خطوط أبل (SF / SF Arabic)** — رخصتها للواجهات على أجهزة أبل بس، ما تنفع بالريلز. «كينوت» اسم ستايل، مو تقليد آبل: لا شعارها ولا أيقوناتها.
