# مونتاج إعلان الفيديو — بلا برنامج مونتاج

المونتاج كله كود: ffmpeg يقص، وِسبر يفرّغ بتوقيت الكلمة، ومحرّك رسم يركّب الكابشن والموشن قرافيكس فوق الفيديو. المخرَج MP4 واحد جاهز للنشر.
مو للكاروسيل (carousel-creator) ولا لكفر الفيديو (animated-video-cover).

## ثلاثة أوضاع — اقرأ المدخل وامشِ

| | **إعلان كلام** (الافتراضي) | **مونتاج مقاطع** | **بودكاست** |
|---|---|---|---|
| المدخل | فيديو واحد فيه شخص يتكلم | مجلد مقاطع بلا كلام (مقهى · سفرة · منتج) | كاميرتان أو أكثر لنفس الجلسة |
| الاختيار على | الكلام (السكتات والجمل المعادة) | المشهد (وضوح · حركة · إضاءة) | من يتكلم + الزاوية |
| كابشن؟ | نعم، متزامن بالكلمة | ⛔ لا — ولا تفريغ | نعم، كلمتين-ثلاث |
| الخطوات | 0-11 تحت | `references/montage.md` | `references/podcast.md` |

**البودكاست له مخرجين:** ريلات عمودية (الافتراضي) — أو **الحلقة كاملة بالعرض 16:9 لليوتيوب** لو قال «الحلقة كاملة / يوتيوب / بالعرض»: `scripts/24_podcast_wide.py` (مزامنة الكاميرات + تنقّل حسب المتكلم + لقطة واسعة) → `references/podcast.md` قسم «الحلقة كاملة بالعرض».

**🎞️ وضع رابع — شرح بالموشن (بلا شخص ولا فيديو):** المدخل نص أو فكرة أو سكربت ← صوت (صوته، أو مولّد مجاني) ← فيلم موشن ثلاثي الأبعاد 60 فريم → `motion/README.md` ثم `motion/ENGINE-API.md`.
- ⛔ **وكيل واحد يبني الفيلم كامل من برومبت واحد** — بلا فريق ولا حكّام ولا نقّاد إلا لو طلب «لمّعه». (بالتجربة: وكيل واحد ≈ 20 دقيقة لفيلم 46 ث بجودة عالية؛ فريق كامل + نقّاد أخذ ساعات وكسر التناسق.)
- **الرتم:** جملة ≈ مشهد، ضربة أو تغيير كل 0.5-1 ث، بس أي كلمة على الشاشة تبقى ≥ 0.6 ث تنقرا. لا تقصّ الفراغات لين يصير لاهث.
- **سقف الجودة (البرومبت حرفياً):** «Craft a high-energy motion graphics piece that flexes your top-tier animation skills like a killer portfolio reel. Pull out all the stops, like the creative work on Dribbble, fps 60» — ثلاثي أبعاد + رسم خط + حروف عربية تتحرك، عين ما ترمش.
- **لا قالب:** اعصف 3 أفكار بنفسك، انقدها، طوّر الأقوى، وكل جملة تنشاف بلحظة ما تنقال.
- **الصوت المولّد:** فصحى مشكّلة كاملة (اللهجة بالأصوات المجانية مكسّرة). تاء مربوطة آخر الجملة ← «ه» بنص الصوت، لا ألف خنجرية، اسم إنقليزي بحروفه (Opus). راجع كل سطر بعينك وبوِسبر medium **قبل** الرسم، وأرسل له الصوت يسمعه.
- **الصوت بالفيلم: الكلام + مؤثرات صوتية بس** — ⛔ بلا ملف صوتي بالخلفية افتراضياً (`audio.py <proj> --no-bed`)؛ اللي يبي خلفية يضيفها بنفسه.
- **سلّم مسودة بدري** (ورقة لقطات أو نص الجودة) قبل الرسم الكامل.
- **شرح موقع أو تطبيق** (رابط موقع، أو «اشرح للناس شلون يسوون كذا بالتطبيق»): لقطات حقيقية داخل إطار جوال/كمبيوتر مرسوم — `scripts/27_web_capture.js <url>` يصوّر الموقع (شاشات + تمرير + نصوصه وألوانه)، و`scripts/31_device3d.js` يطلّع ديمو بآيفون أو ماك بوك **ثلاثي الأبعاد حقيقي** (معدن وزجاج وظل، يلف ويقرّب على الزر — `30_demo.js` نسخته المسطّحة السريعة) من اللقطات أو تسجيل الشاشة → `references/web-app-explainer.md`.

⛔ **لا تسأله «أي وضع تبي؟»** — قل له بجملة وحدة شنو فهمت وكمّل.

**المحرّك:** دائماً الخفيف (`04_render_frames.js`) وبلا ما تذكر كلمة «محرّك». **يبي يعدّل بنفسه؟** افتح له الاستوديو (تايملاين باللمس من الجوال أو المتصفح) → `references/studio.md`. شاشة ريموشن بس لو طلبها بالاسم → `references/remotion.md`.

## ⛔ أسلوبك مع المستخدم

**أنت اللي تجهّز، مو هو.** ممنوع تعطيه قائمة أوامر ينفّذها.
- **لا تسأله «عندك جذيه؟»** — افحص بنفسك، وإذا ناقص شي: «ناقصني أداتين أجهّزهم لك الحين، ياخذ دقيقتين — أبدأ؟»
- **بلا مصطلحات** — «أداة ترسم الشرائح» لا «puppeteer»، «جودة الفيديو» لا «كوديك».
- **قل له وين احنا كل خطوة** وقدّر الوقت: «شلت السكتات — نصف الفيديو راح. الحين أفرّغ كلامك، 3 دقايق.»
- **شي واحد بكل مرة.** و**لا تسلّم بلا ما تريه** لقطة أو ملخصاً بعد كل مرحلة مهمة.

## ⛔ وين يشتغل؟ على جهازه فقط
عبر **Claude Code على الجهاز** (ماك، وويندوز من v2.8): يحتاج ffmpeg وموديل وِسبر ومتصفحاً للرسم. **داخل الشات (claude.ai أو تبويب Chat) المونتاج نفسه ما يشتغل** — بيئته سحابية: ما توصل لملفات جهازه، وتنزيل موديل وِسبر محجوب، وما فيه متصفح للرسم. `00_setup.sh` يكتشف هذا. اللي يقدر يسويه بالشات بدون ما يرفع شي: **السكربت** (هوك + مشاهد)، **خطة المونتاج** (وين الوجه ووين الرسم لكل جملة)، **الثيم من صوره المرجعية**، و**كابشن البوست**. وبعدها جملة وحدة: «المونتاج نفسه افتحه بـClaude Code على جهازك (تبويب Code ← Local) وقل نفس الطلب — كل اللي سويناه هني يمشي معاه».

   - **أرسل صور مرجعية** (حتى بدون ما يقول «مرجع»: صور ستايل + «أبي جذي») → `python3 scripts/00_theme_refs.py <work> صورة1 صورة2 …` يطلّع الألوان بتباين مقروء ويكتب `theme.json` + `refs_palette.jpg`. **اقرأ الورقة بعينك**، وبعدها قرار الذوق منك من شكل الصور: الخط (`font`)، ستايل الكابشن (`capStyle`: ناعم ← `shadow`/`underline` · جريء ← `card`/`big`)، والإيقاع (`"pace":"calm"` لصور هادية). قل له بسطر: «أخذت من صورك: خلفية كذا وتمييز كذا وكابشن كذا — تمام؟». صوّر شي بالجوال وفيه ظل أو إضاءة صفرة؟ `--light`/`--dark` يثبّت الاتجاه.
3. اكتب `<work>/theme.json` وانسخ شعاره `logo.png`:
```json
{ "bg":"#101828", "ink":"#F5F7FA", "acc":"#F2B33D", "clay":"#C98B18", "mut":"#98A2B3",
  "font":"Tajawal", "handle":"@his_handle", "logo":"logo.png", "grade": false,
  "faceAnchor": 0.30, "badgeUntil": 0, "capStyle": "card" }
```
- كل الرسم يشتق ألوانه من هذي القيم (الكروت والظلال ولون النص فوق التمييز). غامق أو فاتح، الاثنين يشتغلون.
- **شارة الحساب مطفية** (`badgeUntil: 0` الافتراضي) — الاسم بالمنصة نفسها وبكرت النهاية. `badgeUntil: 3` تعيدها أول 3 ثوانٍ لو طلبها.
- `hookZoom` (ثواني = نهاية الهوك، مطفي افتراضاً): زوم داخل ناعم أول الهوك **على وجهه** (`python3 scripts/22b_hook_center.py <work>` بعد الخطوة 6 يكتب `hookCenter`؛ بدونه ياخذ الوجه من behind.json) + انتقال زوم عند بداية الكلام — ومعه ووش خفيف جداً بـ`sfx.json` ← `"soft":[[0,0.035],[نهاية_الهوك-0.22,0.06]]`.
- `outro` (اختياري): كرت الختام `{l1,l2,chips:[…],cta,word,sub}` — ⚠️ الافتراضي إعلان السكل نفسه («علّق بكلمة فيديو»)، فأي فيديو مو إعلان للسكل (ريل بودكاست مثلاً) لازم يغيّره.
- `hook` (يكتبه `22_hook.py apply` — لا تكتبه باليد): جملة هوك مكتوبة أول 1.5-3 ث من كل ريل بودكاست/مقابلة/حلقة، ألوانها من هالثيم نفسه. التفاصيل: `references/podcast-hook.md`.
- `grade` مطفي — شوف القاعدة 4 تحت. `capStyle` وحركات الكلمة: `references/word-fx.md`. `"pace":"calm"`: `references/explainer-and-pace.md`.

## ⛔ القواعد الثابتة
1. **المؤثر الصوتي بلحظة لها معنى** (رقم ينزل، شي ينكسر، مشهد ينتقل) — مو رشّ على كل كلمة. 15 حدثاً بالدقيقة بالكثير، الذروة تحت ‎-18 dBFS، واعرض عليه وين حطّيتها قبل التصدير.
2. **أرقام غربية دائماً** (0-9).
3. **الألوان من `theme.json` لا غير** — لا لون ثابت بالكود.
4. **صفر تعديل لوني على صورته** — لا تدرّج ولا صبغة ولا LUT ولا بلر (`grade:false`)، إلا بطلب صريح منه. الألوان للكروت والنصوص فقط. الاستثناء الوحيد: `"grade":"auto"` بعد ما يوافق على نتيجة فحص الإضاءة (`25_scopes.py`).

7. **لا نشر ولا جدولة** — التسليم ملف بس.
8. **«ورا الشخص» و«طبقات» وأنماط القصّ مرة أو مرتين بالفيديو** — أكثر يفقد أثره. وكل `build`/`stack` = القائمة الكاملة لنوعه (اللي ما ذكرته ينشال)، والنص القدّامي ما ينكتب على الوجه أبداً.

11. **أي صورة أو تسجيل شاشة أو شعار بنسبته الأصلية** — تصغير/تكبير نسبي فقط، لا ضغط ولا قصّ إلا بطلب صريح.

14. **الهوك فيه حركة بأول ثانية** — زوم إن سريع ناعم، أو أيقونات تطلع من ورا ظهره. أول فريم ثابت = سكرول.
